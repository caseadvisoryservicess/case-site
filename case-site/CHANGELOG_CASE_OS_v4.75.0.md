# CASE OS v4.75.0

Десять замечаний владельца к студии геоаналитики после v4.74.0, со скриншотами Felt и
Google Earth: карта не должна ничего открывать по клику, внизу нужна панель инструментов как
в Felt, по правому клику меню как в Google Earth, гео-агента в отдельную панель справа,
зоны охвата любого радиуса и по методике CASE, лишнее из левой панели убрать, легенду
перенести на карту, флаг у атрибуции убрать.

## Что изменилось

- **Левый клик по карте ничего не открывает.** Флажок «клик = отчёт по точке» убран из
  «Анализ локации»; «Отчёт по точке» больше не всплывает от случайного клика. Карточка
  открывается кликом по объекту, отчёт по точке остаётся по своей кнопке.
- **Панель инструментов внизу по центру карты (`os/v4750-geo-tools.js`).** Как в Felt:
  отмена и повтор (Ctrl+Z, Ctrl+Y) | пин `P` | полигон по точкам `O` (Enter, двойной клик
  или клик по первой вершине замыкает, Esc отменяет) | полигон от руки `F` (тянуть мышью,
  обводка упрощается по Дугласу-Пекеру) | буфер: круг заданного радиуса `C` (клик центр,
  клик радиус, затем точное значение в км) | маршрут между двумя точками `R` (по дорогам OSM
  через OSRM из браузера, километры и минуты; без маршрутизатора расстояние по прямой) |
  комментарий на карте `M` (хранится в браузере) | стиль карты (кнопка подложки).
  Пин ставит точку анализа гео-агента; полигон и круг становятся фигурами зоны агента, он
  сразу считает площадь, население и конкурентов в зоне. Каждое действие отменяется и
  повторяется. Хоткеи не срабатывают в полях ввода.
- **Контекстное меню по правому клику.** «Добавить метку здесь (точка анализа)», «Круг
  охвата отсюда…», «Маршрут отсюда…», «Переместиться сюда», «Получить сведения» (координаты,
  район, ближайший БЦ, расстояние до точки анализа, адрес из OpenStreetMap), «Скопировать
  координаты», «Вставить объект из буфера обмена» (координаты ставят точку, текст уходит
  агенту как адрес).
- **Гео-агент в правой выдвижной панели (`os/v4750-geo-layout.js`).** Одна кнопка «✦
  Гео-агент» у карты открывает панель, крестик или Esc закрывает; состояние помнится. Панель
  открывается сама, когда нарисована фигура, но фокус остаётся на карте, чтобы хоткеи
  продолжали работать. В левой панели агента больше нет.
- **«Анализ локации» без «Зона: рисовать / Замкнуть / ✕».** Полигоны рисуются панелью
  инструментов; изохрона, отчёт по точке и остальное на месте.
- **«Зона охвата»: свои радиусы.** Поле «радиусы, км» принимает любые значения через
  запятую (до восьми, до 50 км), кольца перестраиваются вокруг точки, выбор помнится; каждое
  кольцо включается галочкой. Зона любой формы: полигон `O` или `F`, круг `C`.
- **Агент считает зоны охвата по методике CASE.** Команда «зона охвата по методике» (или
  «catchment», «торговая зона 10/20/30 мин», «зона охвата 5 10 15 мин, community», «зона
  охвата, GLA 20000, ставка $25»): три пояса PTA / STA / TTA по времени в пути на автомобиле
  (изохроны OSRM; без маршрутизатора радиусы 0,4 км на минуту, об этом сказано явно),
  население по калиброванной сетке, домохозяйства по 4,5 человека, RDE по $349 на человека
  в год (Ташкент, 2024), при заданных GLA и ставке требуемый оборот при rent-to-sales 15%,
  доли 75 / 20 / 5 и capture rate по поясам с ориентиром CASE 0,39%; capture rate выше 2%
  сопровождается предупреждением. Всё помечено «расчёт», в ответе список «Требуемые входные
  данные» (доходы по зонам, опрос жителей, коррекция границ по барьерам). Пояса рисуются на
  карте и убираются «очистить всё».
- **Дерево слоёв без узла «Подложка карты».** Подложку меняет кнопка у карты (и кнопка
  «стиль карты» на панели инструментов).
- **Атрибуция без флага.** Префикс Leaflet заменён на простую ссылку.
- **«Легенда» в плашке «На экране».** Обозначения (бизнес-центр, точка анализа,
  отредактированная запись) добавлены в плашку внизу слева; отдельной секции «Легенда» в
  левой панели больше нет.
- Автономный файл `docs/standalone/CASE_Geo_Analytics.html` пересобран с теми же модулями.

- `os/v4750-geo-tools.js`: панель `#geoTb`, подсказка `#geoTbHint`, уведомление `#geoToast`
  внутри контейнера карты (центр карты, а не страницы); стек отмены `{label, undo, redo}`;

  contextmenu`; фигуры уходят агенту через `A.run('draw_polygon' | 'draw_circle' | 'set_site')`.

  `updateLegend` студии оборачивается и дописывает блок обозначений; `buildRings /

- `os/geoanalytics-studio.html`: убраны флажок отчёта по точке, кнопки зоны и секция
  «Легенда»; добавлено поле радиусов; подключены два новых модуля.
- Проверки: `v4750_geo_tools.js` (65: компоновка, клик без отчёта, панель и хоткеи, пин с
  отменой и повтором, полигон по точкам и от руки, круг, маршрут и запасной путь,
  комментарии с памятью, контекстное меню, свои радиусы, зоны охвата с подменённым OSRM и
  без него), обновлены `v4730_geo_agent.js`, `v4740_geo_tree.js`, `v4740_geo_only.js`,
  `v4732_standalone_build.js`.

## Ловушки

- Автоматическое открытие панели агента не должно переводить фокус в строку ввода: иначе
  следующие хоткеи печатаются в поле, и пользователь думает, что панель сломалась.
- Панель внизу «по центру» надо класть внутрь контейнера карты: центр родителя с левой
  колонкой не совпадает с центром карты.
- Дугласа-Пекера при совпадающих концах отрезка (замкнутая обводка) даёт нулевые расстояния
  для всех вершин: в этом случае считать расстояние до точки.
- Комментарии нельзя сериализовать вместе с маркером Leaflet (циклическая структура):
  в localStorage уходят только id, координаты, текст и время.
