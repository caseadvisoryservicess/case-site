# CASE OS v4.50.6 — установка

Включает v4.50.1–v4.50.5. Миграций базы нет, кода не меняли.

## Коротко

1. Скачайте `CASE_OS_v4.50.6_os_only.zip`.
2. DirectAdmin → Менеджер файлов → `domains/caseadvisory.uz/public_html/`.
3. Распакуйте с **перезаписью** папки `os`.
4. `Ctrl+Shift+R`. В шапке должно быть **v4.50.6**.

## Что изменилось

В пакет добавлены границы 12 районов Ташкента — из вашего архива, данные за 2024 год,
включая Янгихаёт.

Раньше этот слой брался из интернета, с GitHub. Когда GitHub недоступен — а у нас это
не редкость, вы сами видели, как отваливаются тайлы карт, — районы просто не появлялись,
без всякого сообщения. Теперь они в пакете и работают всегда, в том числе без сети.

## Проверка после установки

Геоаналитика → в панели слева включите слой **«Районы (граница+заливка)»**. Должны
появиться 12 районов с заливкой и подписями. Наведите на любой — во всплывающей подсказке
будут население, площадь и плотность.

## Что пока осталось из интернета

Слой **«+ Ташкентская область (22 территории)»** по-прежнему подгружается с GitHub.
Если пришлёте такой же архив по области — добавлю так же, и гео-модуль перестанет
зависеть от внешних источников полностью.
