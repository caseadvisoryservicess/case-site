# CASE OS v4.48.3 — «Бюджет / Факт» больше не уходит при прокрутке

Дата: 2026-07-25. Ответ на «при сдвиге вниз строка Бюджет и Факт уходит».

## Что сделано

**1. Полоса «Бюджет / Факт» теперь прилипает.** Групповая строка стала
прилипающей полосой над рядом колонок: при прокрутке вниз сверху остаются ОБЕ
строки шапки — «▾ Бюджет / ▾ Факт» и названия колонок под ними. По горизонтали
полоса едет вместе с таблицей сама (обычный блок в потоке — ему не нужна
синхронизация, в отличие от ячеек таблицы, которые Chromium отказывается
закреплять по двум осям). Клик по «Бюджет»/«Факт» работает как раньше
(сворачивание группы).

**2. Найден и обезврежен изначальный виновник всей серии багов шапки.**
Старый UX-модуль (v3515) все эти версии держал правило «все заголовки таблиц —
top:0 !important», которое молча перебивало любые вертикальные смещения рядов
шапки. Именно из-за него исторически «не работали» родные прилипания и была
придумана копия-клон. Правило нейтрализовано.
