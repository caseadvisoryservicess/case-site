# Telegram-бот обратной связи CASE OS (v4.77.0)

Пользователи платформы пишут предложения, проблемы и вопросы двумя путями:

1. **Форма в платформе** (меню профиля «Обратная связь», личный кабинет). Это основной путь:
   работает на хостинге без дополнительной настройки, обращения видит администратор на
   странице «Доступ» в карточке «Обращения», ответ виден пользователю в кабинете.
2. **Telegram-бот** из этой папки. PHP на хостинге CASE OS не имеет выхода в интернет,
   поэтому бот работает на любой машине с Node.js 18+ и интернетом и сам присылает
   сообщения в платформу по адресу `api/feedback.php` с секретным токеном.

## Настройка

1. В Telegram у @BotFather создайте бота, получите токен.
2. В `os/api/config.php` на хостинге добавьте строку
   `'feedback_bot_token' => 'ДЛИННАЯ_СЛУЧАЙНАЯ_СТРОКА',` (см. `config.sample.php`).
3. На машине, где будет работать бот, создайте файл `bot/.env`:

```
TG_BOT_TOKEN=123456:токен-от-BotFather
CASE_API_URL=https://ваш-домен/os/api/feedback.php
CASE_BOT_TOKEN=ДЛИННАЯ_СЛУЧАЙНАЯ_СТРОКА
# TG_ALLOWED_IDS=11111111,22222222   (необязательно: принимать только от этих Telegram id)
```

4. Запуск: `node bot/telegram_feedback_bot.js`. Для постоянной работы на сервере
   используйте `pm2 start bot/telegram_feedback_bot.js --name case-bot` или systemd.

## Как работает

- Бот опрашивает Telegram (long polling), вебхук и публичный адрес не нужны.
- Команды `/idea`, `/problem`, `/question` (или `/предложение`, `/проблема`, `/вопрос`)
  задают тип обращения; без команды тип «вопрос».
- Каждое сообщение уходит в платформу: `POST api/feedback.php`
  `{action:'bot', token, text, from_name, from_id, kind}`; ответ `{ok:true,id}`.
- Пользователю бот отвечает номером обращения. Ответ команды CASE пользователь видит в
  личном кабинете платформы (в Telegram бот не пишет сам: ответы хранятся в платформе).
- Ошибки сети: бот ждёт с удвоением паузы до минуты и продолжает.

Зависимостей нет: используется встроенный `fetch` Node.js 18+.
