# CASE OS v4.46.2 — установка на хостинг (DirectAdmin)

Исправления дня: таблицы не «мигают» старым видом, селекты не выходят за линию
столбца, у Администратора аренды (тыл) полный доступ к настройкам таблиц.
Подробности — `CHANGELOG_CASE_OS_v4.46.2.md`.

## Шаг 1. Файлы

Замените содержимое папки `/os` содержимым архива `CASE_OS_v4.46.2_os_only.zip`.
`api/config.php` в архиве нет — ваш конфиг не затрагивается. Серверные PHP
относительно v4.46.0 не менялись; если на сервере v4.45.x или старше — заливайте
архив целиком и один раз войдите администратором (миграция ролей).

## Шаг 2. Проверка (3 минуты)

1. В шапке — **v4.46.2** (иначе Ctrl+Shift+R).
2. ЛСР: сузьте столбец «Статус» — селекты остаются внутри столбца.
3. Сохраните что-нибудь из карточки: таблица обновляется мгновенно, без «мигания»
   старым видом, позиция не сбивается.
4. Войдите как Администратор аренды (тыл): на ЛСР/брендах/датах есть кнопки
   «☷ Столбцы» и «⚙ Вид», в панели — скрытие столбцов, закрепление, плотность.
5. «Данные обновлены» появляется только на изменения коллег, не на ваши.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4462`).

## Откат

Файлы из архива v4.46.1 + Ctrl+Shift+R. БД не затрагивается.
