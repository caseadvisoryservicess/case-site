# CASE OS v4.42.2 — изменения

Дата: 2026-07-24. Ветка: `claude/new-session-2kq1ff`. Предыдущая версия: v4.42.1.

## Гео-студия: единые и понятные настройки всех категорий

По замечаниям: у БЦ не было кнопки «подписи» (в шапке слоя стояла безымянная галочка — это
она и была), у части слоёв контролы были «голыми» (только всплывающая подсказка).

Теперь у **всех** слоёв одна логика (`geoanalytics-studio.html`):

- **шапка слоя** — только включатель с названием и шестерёнка ⚙, ничего лишнего;
- **внутри ⚙** — подписанные контролы в одном порядке:
  «цвет · размер · прозр.» → «☑ подписи · размер подписи (· подписи с зума)» → доп.
  тумблеры («цвет по источнику/по ставке», «цвет по линии/маршруту») → «☐ кластеры точек».

Что добавлено/подписано по категориям:

| Слой | Было | Стало |
|---|---|---|
| Бизнес-центры | безымянная галочка подписей и цвет в шапке | «подписи» словом, всё в ⚙-панели |
| Медицина | подписи внутри строки «тип», нет кластеров и размера подписи | «подписи» + «размер подписи» + «кластеры точек» |
| Аптеки | безымянная галочка подписей, размер подписи общий с медициной | «подписи» + свой «размер подписи» + «кластеры точек» |
| Метро | галочки подписей и «цвет по линии» без текста | «подписи станций», «цвет по линии» словами |
| Транспортный коридор | галочка «цвет по маршруту» без текста | подписана, в ⚙-панели |
| Районы | галочка «метки» без текста | «подписи районов» словом |
| Плотность / тепловая карта | цвет и прозрачность без подписей в шапке | «цвет», «прозр.» в ⚙-панели |
| POI-категории (HoReCa, Ритейл и т.д.) | эталон | без изменений |

Кластеры медицины и аптек работают так же, как у БЦ и POI-слоёв (включил — точки
собираются в кружки с числом, выключил — каждая точка отдельно).
