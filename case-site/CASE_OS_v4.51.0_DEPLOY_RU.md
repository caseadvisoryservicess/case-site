# CASE OS v4.51.0 — установка

Включает v4.50.1–v4.50.7. Миграций базы нет.

## Коротко

1. Скачайте `CASE_OS_v4.51.0_os_only.zip`.
2. DirectAdmin → Менеджер файлов → `domains/caseadvisory.uz/public_html/`.
3. Распакуйте с **перезаписью** папки `os`.
4. `Ctrl+Shift+R`. В шапке должно быть **v4.51.0**.

## Главное: теперь справочник ведёте вы сами

**Система → Справочник категорий брендов** — раздел виден только администратору.

Добавляйте свои категории, подкатегории и типы. Добавленное сразу появляется у всех
сотрудников при заведении бренда. Встроенные значения удалить нельзя — на них уже
ссылаются заведённые бренды; свои убираются свободно.

## Про два поля

- **Подкатегория** — формат: Ресторан, Кафе, Кофейня.
- **Тип** — кухня или специализация: Итальянская, Узбекская, Славянская.

«Ресторан — славянская» правильнее заводить как подкатегорию «Ресторан» плюс тип
«Славянская / русская». Иначе на каждую пару формат × кухня нужна отдельная строка.

Славянскую и ещё 11 кухонь я уже добавил — корейская, китайская, индийская, тайская,
мексиканская, арабская, средиземноморская, французская, немецкая, халяль, здоровое
питание. Всего для общепита стало 31 тип.

## Проверка после установки

Система → Справочник категорий брендов → выберите категорию, добавьте значение.
Затем Бренды → добавить бренд → выберите ту же категорию: добавленное должно быть
в подсказках.
