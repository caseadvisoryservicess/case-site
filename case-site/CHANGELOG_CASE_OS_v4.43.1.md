# CASE OS v4.43.1 — изменения

Дата: 2026-07-24. Ветка: `claude/new-session-2kq1ff`. Предыдущая версия: v4.43.0.

## Геоаналитика: авто-отчёт по проекту и выгрузка в PDF

По замечаниям к переходу «Карта объектов → Аналитика».

1. **Отчёт по точке открывается сам.** При переходе «Аналитика» из «Карты объектов»
   геоаналитика, как и раньше, ставит точку проекта — но теперь сразу автоматически
   открывает панель «🎯 Отчёт по точке» по координатам проекта (население по радиусам,
   конкуренция БЦ, медицина, скоринг). Кликать по карте рядом с проектом больше не нужно.
   Отчёт открывается один раз за переход; при обычном открытии гео-разделов из меню
   ничего само не выскакивает (`v493-portfolio-suite.js` → `v420-geoanalytics.js` →
   `v420-geo-studio.js`, флаг probeProjectId в контексте).

2. **«⤓ Скачать PDF» в отчёте по точке.** Проверил: PDF-выгрузки в отчёте не было
   (только «Экспорт CSV») — добавил. Кнопка формирует печатную версию полного отчёта
   (шапка CASE OS, проект, дата, локация и метро, население по всем радиусам,
   бизнес-центры с ближайшими, медицина/аптеки, быстрый скоринг, источники данных)
   и открывает диалог печати браузера — «Сохранить как PDF» (`geoanalytics-studio.html`,
   `exportProbePdf`, отчёт запоминается в `LASTPROBE.html`).
