# CASE OS v4.50.1 — установка

## Коротко

1. Скачайте `CASE_OS_v4.50.1_os_only.zip`.
2. DirectAdmin → Менеджер файлов → `domains/caseadvisory.uz/public_html/`.
3. Распакуйте с **перезаписью** папки `os`.
4. `Ctrl+Shift+R`. В шапке должно быть **v4.50.1**.

Архив содержит только папку `os`, без `config.php` — доступ к базе не затрагивается.

## Что изменилось

Изменены `os/index.html`, `os/v4327-patch.js`, `os/sw.js`. Ядро `core.js` не менялось
и останется в кэше браузера — обновление лёгкое. Серверные PHP не трогали, миграций нет.

Если сервер отклоняет правку помещения, введённое значение теперь **возвращается
к прежнему** прямо на экране. Раньше оно оставалось висеть как сохранённое, и
сотрудник узнавал о потере только после обновления страницы.

## Важно про Асада (роль «Младший админ брендов»)

После установки он увидит при правке реестра сообщение вида:

> ⛔ Сервер отклонил правку помещения: Для этой роли LCR доступен только для просмотра.
> Значение возвращено к прежнему — сообщите администратору.

Это не поломка, а честное отражение прав: сервер закрывает правку помещений для
ролей `AGX`, `BSH` и `BRJ`. Раньше запрет был тот же, просто выглядел как пропажа данных.

Дальше решаете вы:

- **Он не должен править реестр** — оставляем как есть, скажите ему, что реестр
  для него только для просмотра. Могу дополнительно убрать у него кнопки правки,
  чтобы не пробовал.
- **Он должен править реестр** — скажите, и я сниму запрет на сервере и добавлю
  роли рабочую область «реестр». Учтите: он получит доступ к ставкам и бюджетам
  всех помещений.

