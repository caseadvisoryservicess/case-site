# CASE OS v4.43.0 — установка на хостинг (DirectAdmin)

Включает всё из v4.42.x + серверное хранение личных настроек таблиц.
**В этом релизе добавлен новый серверный файл `os/api/user_prefs.php`** — он входит в
архив и просто копируется вместе с остальным; `config.php` не затрагивается.
Таблица в базе создаётся автоматически при первом обращении — SQL вручную не нужен.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.43.0_os_only.zip` (без секретов).
2. Замените содержимое `/os` файлами из архива.
3. Жёсткая перезагрузка: **Ctrl+Shift+R**. В шапке — **v4.43.0**.
4. Если не делали после v4.42.1 — один вход администратором (миграция шаблонов ролей).

## Проверка настроек таблиц

1. В «Реестре» перетащите границу столбца, скройте пару столбцов через «☷ Столбцы».
2. Перейдите в другой раздел и вернитесь — вид сохранён.
3. Откройте платформу в другом браузере (или в режиме инкогнито) под тем же логином —
   через пару секунд таблицы примут ваш сохранённый вид.
4. Под другим логином вид останется стандартным — настройки у каждого свои.
