# CASE OS v4.48.1 — установка на хостинг (DirectAdmin)

Шапка держится и по вертикали, и по горизонтали; скрытие столбцов атомарно
(шапка и тело всегда синхронны). Подробности — `CHANGELOG_CASE_OS_v4.48.1.md`.

## Шаг 1. Файлы — залить ЦЕЛИКОМ

Замените ВСЁ содержимое папки `/os` содержимым архива
`CASE_OS_v4.48.1_os_only.zip`. `api/config.php` не затрагивается. Серверные PHP
не менялись.

## Шаг 2. Проверка (2 минуты)

1. Ctrl+Shift+R → в шапке **v4.48.1**, жёлтого предупреждения о старых файлах нет.
2. ЛСР → прокрутите вниз: ряд названий колонок прилип сверху (групповой ряд
   «Бюджет/Факт» уезжает — это штатно).
3. Прокрутите вправо-влево: шапка идёт вместе с телом, линия в линию.
4. Закрепите 3–4 столбца: они стоят слева вместе со своими заголовками.
5. «☷ Столбцы» → скройте любой столбец: он исчезает и из шапки, и из тела
   одновременно; верните обратно.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4481`).

## Откат

Файлы из архива v4.48.0 + Ctrl+Shift+R. БД не затрагивается.
