# CASE OS v4.48.3 — установка на хостинг (DirectAdmin)

«Бюджет / Факт» прилипает вместе с названиями колонок — обе строки шапки всегда
видны. Подробности — `CHANGELOG_CASE_OS_v4.48.3.md`.

## Шаг 1. Файлы — залить ЦЕЛИКОМ

Замените ВСЁ содержимое папки `/os` содержимым архива
`CASE_OS_v4.48.3_os_only.zip`. `api/config.php` не затрагивается. Серверные PHP
не менялись.

## Шаг 2. Проверка (2 минуты)

1. Ctrl+Shift+R → в шапке **v4.48.3**, жёлтого предупреждения о старых файлах нет.
2. ЛСР → прокрутите вниз: сверху остаются «▾ Бюджет / ▾ Факт» И названия колонок.
3. Прокрутите вправо-влево: полоса и колонки едут вместе с телом, линия в линию.
4. Закрепите 3–4 столбца: угловой блок слева, всё согласовано при любых прокрутках.
5. Клик по «▾ Бюджет» сворачивает группу, как раньше.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4483`).

## Откат

Файлы из архива v4.48.2 + Ctrl+Shift+R. БД не затрагивается.
