82 Mall / 82 Towers

Concept and leasing on one asset: our difference in action.

Updated: 2026-08-19

The owner's problem

The owner held a site in Dushanbe and intended to build a large mixed use asset. The open question was the one that decides everything: how large the retail component should be and what it should contain, so that it lets and holds footfall instead of becoming an empty ground floor under apartments.

Stage we entered and product sold

We entered before the architectural decisions were locked and stayed with the project down the chain: concept and merchandise mix first, then leasing as execution of the approved strategy.

Solution

We set the format and the size of the retail component, built the split by category, defined the zoning and tested the layout for circulation. A tenant pool was assembled against the approved programme: anchors first, supporting categories after. Leasing ran off the same table the concept was calculated on, so the tenant list did not drift away from the model.
