# CASE OS v4.50.7 — установка

Включает v4.50.1–v4.50.6. Миграций базы нет.

## Коротко

1. Скачайте `CASE_OS_v4.50.7_os_only.zip`.
2. DirectAdmin → Менеджер файлов → `domains/caseadvisory.uz/public_html/`.
3. Распакуйте с **перезаписью** папки `os`.
4. `Ctrl+Shift+R`. В шапке должно быть **v4.50.7**.

## Что изменилось

Комментарии в реестре теперь ведут себя предсказуемо:

- печатаете сколько угодно — никто не прервёт: текст переживает любые обновления
  таблицы, фокус не теряется;
- **сохранение только по Enter** — само ничего не сохраняется;
- ушли из поля не дописав — текст ждёт вас там же, где оставили.

Раньше поле сохраняло недописанный текст при любой потере фокуса, а обновление
таблицы выбрасывало из поля прямо во время набора. Отсюда и «сохраняет сам по себе»,
и огрызки фраз в комментариях.

## Проверка после установки

Реестр → поле «+ комментарий…» в любой строке. Начните печатать и, не заканчивая,
кликните в другую ячейку. Вернитесь — текст на месте, в комментарии ничего не
добавилось. Допишите и нажмите Enter — комментарий сохранился, поле очистилось.

Скажите сотрудникам: **комментарий сохраняется клавишей Enter**.
