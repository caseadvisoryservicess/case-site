# CASE OS v4.56.0 - профили конкурентов прямо в аналитике

По запросу: «on analytics side I want to see every competitor profile's informations
also. their price, GLA, GBA and etc».

Раньше в отчёте по точке была одна строка: «Ближайшие: Trilliant (513 м), Park view
(580 м)…». По ней ничего не решишь - ни ставки, ни площадей, ни этажности.

## Что теперь на экране

В отчёте по точке появился блок **«Конкуренты рядом»** - таблица с теми же колонками,
что уходят в презентацию: **Объект (с адресом) · Тип · Год открытия · GBA · GLA ·
Этажей · Точки · F&B · Парковка · Ставка · Расстояние**. Наши проекты подсвечены.

**Клик по строке открывает полную карточку объекта** - со всеми полями и правкой,
там же можно сразу дописать недостающее.

Список тот же, что уходит в Excel и презентацию, и считается по настройкам проекта
(радиус, кого считать конкурентом, сколько строк) - экран и файлы не расходятся
по определению, потому что источник один.

Прочерк в ячейке значит, что данных в базе нет. Система не подставляет ни средних,
ни «примерно»: по таким числам принимают решения об аренде.

## Мелочи, которые делают таблицу читаемой

Панель отчёта расширена до 720 px - в 390 px одиннадцать колонок не помещались.
Таблица прокручивается вбок внутри своей рамки, а не обрезается по краю панели;
шапка при прокрутке остаётся на месте. На узком экране панель возвращается к 390 px.

## Проверено

`v4530_geo_export.js` дополнен шестью проверками: таблица есть в отчёте, колонки те же,
что в презентации, строк не меньше трёх, каждая строка кликабельна, пустые поля
показаны прочерком, а клик действительно открывает карточку объекта (проверяется
перехватом вызова).
