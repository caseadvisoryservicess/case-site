# CASE OS v4.43.3 — изменения

Дата: 2026-07-24. Ветка: `claude/new-session-2kq1ff`. Предыдущая версия: v4.43.2.

## Правки в таблицах видны сразу — перезагрузка страницы больше не нужна

Жалоба: «меняю что-то в разных таблицах, сохраняю — чтобы отобразилось, приходится
перегрузить страницу».

**Диагноз.** Обработчик построчной правки (`saveCellLive` — режим «✎ Правка» в LCR,
вкладки «Таблица» и «План / бюджет») сохранял данные, но не обновлял экран: полная
перерисовка украла бы фокус из поля ввода, поэтому её не делали вообще. В итоге
вычисляемые колонки («Итого аренда», «Обслуживание», «Итого вкл. обсл.», «Разница»)
и бейдж «% занято» показывали старые значения до перезагрузки страницы.

**Решение.** Точечный пересчёт без перерисовки: после каждого сохранения обновляются
только вычисляемые ячейки этой строки (строки получили идентификатор `data-uid`) и
бейдж «% занято» (при изменении площади, ставки или статуса). Поле ввода остаётся тем
же DOM-элементом — фокус и позиция курсора не теряются, можно править дальше подряд.

Проверка: ставка «Бюджет» 20 $/м² на помещении 367.5 м² → «Итого аренда» тут же
показывает $7,350, «Итого вкл. обсл.» $8,085 — без перезагрузки, фокус в поле.
