Смягчённая редакция того же пункта - FL2:571 («могут быть **увеличены или уменьшены** по взаимному согласию сторон»).

# ЧАСТЬ 3. Конкурент CMWP - структурные отличия

Источник: `competitor-CMWP.txt`, «Разработка концепции креативного кластера в г. Ташкент. Краткое изложение коммерческого предложения. Октябрь 2025», 12 слайдов.

## Ценообразование - главное отличие

| | CASE | CMWP |
|---|---|---|
| База цены | ставка × расчётная площадь (2,0-4,5 USD/м²) | **фиксированная сумма за проект** |
| Цитата | CHG:150 «Тариф 1: 2,0 USD; Тариф 2: 2,5 USD (рекомендуем); Тариф 3: 4,5 USD» | CMWP:218-220 «ЦЕНА (не включая НДС) / Стоимость работы: / $45 000» |
| Срок | в неделях, по тарифам (CHG:139) | CMWP:216-217 «СРОК ВЫПОЛНЕНИЯ / 90 календарных дней» |
| График платежей | 40/30/30 (или 40/40/20) с привязкой к отчётам | **не найдено** |
| Методика площади | детальная, с включениями/исключениями по уровням | **не найдено** (площадь вообще не фигурирует) |
| Тарифная линейка | 3 тарифа на выбор, каждый включает предыдущий | **один пакет, выбора нет** |
| Условия и положения (юр. блок) | 5 пунктов | **не найдено** |
| Подпись заказчика | есть | **не найдено** |

## Структура документа

**CMWP** - презентация из 12 слайдов: 2 слайда кредентиалов по Узбекистану с описанием проектов (Tashkent City, Samarkand City, Business City Tashkent, Sea Breeze Uzbekistan, Заамин, Чорсу), затем цель проекта, затем **4 этапа**, каждый на отдельном слайде по единому шаблону «Цель этапа → Основные задачи → Результат», затем цена и Company Profile:

> Этап 1 АНАЛИТИКА И ДИАГНОСТИКА ТЕРРИТОРИИ … Результат: аналитическая записка с выводами и рекомендациями для дальнейшей работы (CMWP:135-154)
> Этап 2 ФОРМИРОВАНИЕ КОНЦЕПЦИИ РАЗВИТИЯ … Результат: презентация с ключевыми идеями и схемами (CMWP:158-171)
> Этап 3 АРХИТЕКТУРНО-ПЛАНИРОВОЧНАЯ КОНЦЕПЦИЯ* … Результат: архитектурная концепция с визуализациями и планами (CMWP:175-191)
> Этап 4 РЕКОМЕНДАЦИИ ПО ОПЕРАЦИОННОМУ УПРАВЛЕНИЮ … Результат: итоговый документ «Концепция развития креативного кластера» в формате презентации (PDF) (CMWP:198-215)

**CASE** - деловое письмо + разделы А/Б/В по видам работ (исследование / концепция / ТЭО), без этапности и без «Результат» на каждом этапе.

Ключевое: **у CMWP результат привязан к этапу, у CASE - к разделу работ.** У CMWP каждый этап заканчивается названным артефактом. У CASE «Ожидаемые результаты» указаны по блокам А/Б/В (FL2:486, 512-514, 535-537), а связи «этап → платёж → артефакт» в документе нет; платёж привязан к «черновому» и «окончательному отчёту» абстрактно (CHG:155-156).

## Содержательные отличия

1. **Уровень задачи.** CMWP заходит сверху - идеология, стратегия, позиционирование территории: «СОЗДАНИЕ КОНЦЕПЦИИ СОВРЕМЕННОГО КРЕАТИВНОГО КЛАСТЕРА… НАПРАВЛЕННОЙ НА ФОРМИРОВАНИЕ НОВОЙ ТОЧКИ ПРИТЯЖЕНИЯ» (CMWP:112-118). CASE заходит от коммерции: «обеспечивающие ликвидность аренды, устойчивую посещаемость и доход собственника» (CHG:20).

2. **Финансовая часть слабее.** У CMWP - «Верхнеуровневый расчет P&L проекта» (CMWP:131, 213), одна строка внутри 4-го этапа. У CASE - отдельный раздел В с моделью в Excel, NOI/IRR/NPV, чувствительностью и реестром рисков (CHG:115-129, FL2:516-537).

3. **Роль архитектора зафиксирована сноской.** CMWP:192-194: «CMWP на данном этапе работает совместно с архитекторами Заказчика (выдает ТЗ, вносит рекомендации по корректировке результата работ)». У CASE это же по сути, но растворено в тексте (FL2:513 «Техническое задание (в формате PDF, DWG и в устной форме напрямую проектировщику)»).

4. **Визуализации.** CMWP включает «Подготовка визуализаций ключевых зон» и обещает «архитектурная концепция с визуализациями и планами» (CMWP:188-191). У CASE визуализаций в результатах нет - только цветокодированные планы и Excel.

5. **Кредентиалы поданы по-разному.** CMWP: 6 проектов с описанием, что именно сделано (3-4 буллита на проект). CASE: таблица из 62 строк «№ / Название / Город / Страна / Площадь / Год откр.» без описания работ (CC/FL2:17-457).

6. **Широта компании.** CMWP закрывает слайдом направлений деятельности - брокеридж, эксплуатация, инвестиции, оценка, исследования, управление строительными проектами, техзаказчик, fit-out (CMWP:228-283) - позиционируясь как полносервисная платформа. У CASE такого слайда нет.

## Что имеет смысл забрать у CMWP

- Этапность с именованным артефактом на выходе каждого этапа (у CASE этапы есть в SYS по-узбекски, но в клиентский документ не выведены).
- Явная строка «СРОК ВЫПОЛНЕНИЯ» крупно (у CASE есть только в CHG и мелким текстом).
- Кредентиалы с описанием сделанного, а не таблицей площадей.

## Что у CASE сильнее

- Тарифная сетка с выбором (у CMWP - take it or leave it).
- Прозрачная методика цены (м² × ставка) против непрозрачных $45 000.
- Юридический блок из 5 условий + подпись заказчика (у CMWP не найдено).
- Финансовая глубина (ТЭО против «верхнеуровневого P&L»).
