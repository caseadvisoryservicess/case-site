# CASE OS v4.45.1

Дата сборки: 2026-07-25

## Исправлено

- После сохранения карточки помещения в LCR/SCR соответствующая таблица обновляется сразу без ручного обновления страницы.
- После сохранения карточки бренда таблица результатов обновляется точечно без сброса поиска, фильтров и позиции.
- После сохранения объекта или локации в геоаналитике обновляются таблица, аналитика и карта с сохранением текущей позиции.
- Фоновая серверная синхронизация больше не перерисовывает текущий экран при изменении нерелевантных данных.
- При релевантном обновлении сохраняются вертикальная позиция страницы, горизонтальная позиция таблицы, внутренний скролл, текущий проект и активный раздел.
- Автосинхронизация временно приостанавливается во время сохранения, открытой карточки, модального окна и активного ввода.
- Устранена гонка, при которой фоновое чтение могло попасть между локальной правкой и завершением серверного сохранения.
- Service Worker переведён на кэш `case-os-v4451`.

## Совместимость

- SQL-миграция не требуется.
- Структура данных и серверные API не изменены.
- Ни один файл исходной v4.45.0 не удалён.
