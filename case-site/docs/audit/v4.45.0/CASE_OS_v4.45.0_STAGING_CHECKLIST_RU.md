# CASE OS v4.45.0 - staging checklist

## Развёртывание

- [ ] Создана резервная копия файлов.
- [ ] Создана резервная копия MySQL.
- [ ] Production `config.php` сохранён.
- [ ] Загружены оба новых JS-файла.
- [ ] В интерфейсе показана версия 4.45.0.
- [ ] Активирован Service Worker `case-os-v4450`.

## Базовая работа

- [ ] Вход и выход работают.
- [ ] Смена объекта работает.
- [ ] Поиск работает и не теряет focus.
- [ ] Навигация не показывает запрещённые разделы.
- [ ] Данные v4.44.0 присутствуют.
- [ ] Существующие документы и планировки открываются.

## LCR

- [ ] Один горизонтальный ползунок.
- [ ] Две строки шапки закреплены корректно.
- [ ] Заголовки и тело таблицы совпадают.
- [ ] Прокрутка вверх выходит из таблицы к шапке страницы.
- [ ] Resize колонок сохраняется.
- [ ] Фильтры открываются и закрываются.
- [ ] Бюджет/Факт не сбрасывает ширины и позицию.
- [ ] Изменение юнита сохраняется после перезагрузки.

## Роли

- [ ] ASH имеет полный доступ.
- [ ] CFO имеет полный финансовый доступ.
- [ ] ADM управляет пользователями и модулями.
- [ ] BA редактирует LCR и создаёт отчёт владельцу.
- [ ] HO создаёт отчёт владельцу.
- [ ] AG не видит административные разделы.
- [ ] AGX не видит LCR, проекты и внутренние базы.
- [ ] Прямой URL/route AGX в LCR отклоняется.
- [ ] BSH видит LCR только для просмотра.
- [ ] API отклоняет изменение LCR от BSH.
- [ ] BRJ не видит LCR и проекты.
- [ ] BRJ может работать с брендами и геоданными.

## Отчёт владельцу

- [ ] Кнопка доступна из LCR.
- [ ] Кнопка доступна из проекта/главного экрана.
- [ ] GLA совпадает с карточкой проекта.
- [ ] Сумма статусов совпадает с суммой уникальных юнитов.
- [ ] Один юнит не считается дважды.
- [ ] Подписанные бренды показаны корректно.
- [ ] Переговоры показаны корректно.
- [ ] Отказы и причины показаны корректно.
- [ ] Планировка открывается.
- [ ] PDF/печать работает.
- [ ] CSV открывается в Excel с кириллицей.
- [ ] PPTX открывается без восстановления файла.
- [ ] Снимок сохраняется в истории.
- [ ] Старый снимок не меняется после изменения LCR.
- [ ] В снимке нет ставок, брокеров, комиссий и внутренних комментариев.

## Адаптивность и доступность

- [ ] 1440 px без page-level overflow.
- [ ] 1024 px sidebar компактный.
- [ ] 480 px меню открывается и закрывается.
- [ ] Основные мобильные кнопки удобны для нажатия.
- [ ] Tab-навигация показывает focus.
- [ ] Escape закрывает popover/modal там, где предусмотрено.
- [ ] У полей есть понятные подписи.
- [ ] Длинные тире визуально заменены короткими.
- [ ] Повторяющийся системный toast не дублируется.

## Backend и параллельная работа

- [ ] Два пользователя одновременно редактируют разные юниты без потерь.
- [ ] Устаревшая вкладка не откатывает новый unit_patch.
- [ ] Истёкшая сессия показывает очередь несохранённых правок.
- [ ] После повторного входа очередь дозаливается.
- [ ] 403 не создаёт бесконечные повторные запросы.
- [ ] Резервная копия создаётся и восстанавливается.
