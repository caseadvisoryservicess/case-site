# CASE OS v4.42.3 — установка на хостинг (DirectAdmin)

Включает всё из v4.42.0–v4.42.2 + починены подписи БЦ/медицины на карте.
**SQL-миграций нет, серверные файлы (`os/api/*`) не менялись** — `config.php` не трогаем.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.42.3_os_only.zip` (без секретов).
2. Замените содержимое `/os` файлами из архива.
3. Жёсткая перезагрузка: **Ctrl+Shift+R**. В шапке — **v4.42.3**.
4. Если не делали после v4.42.1 — один вход администратором (миграция шаблонов ролей).

## Проверка карты

Гео-студия → «Слои и стиль» → Бизнес-центры → ⚙ → «подписи» ✓: при зуме от «подписи с
зума» (по умолчанию z13) названия БЦ появляются рядом с точками; ползунок «размер
подписи» меняет их размер. То же у «Медицины».
