# CASE OS v4.46.4 — установка на хостинг (DirectAdmin)

Самовосстанавливающийся клон прилипшей шапки (столбцы не съезжают) + платформа
теперь сама сообщает, если на сервере остались старые файлы.
Подробности — `CHANGELOG_CASE_OS_v4.46.4.md`.

## Шаг 1. Файлы — ВАЖНО залить целиком

Замените ВСЁ содержимое папки `/os` содержимым архива
`CASE_OS_v4.46.4_os_only.zip` (не отдельные файлы — прошлый симптом «та же
проблема» очень похож на частичную заливку: index.html новый, а v4327-patch.js
старый). `api/config.php` в архиве нет — конфиг не затрагивается.

## Шаг 2. Проверка (2 минуты)

1. Ctrl+Shift+R. В шапке — **v4.46.4**.
2. Подождите 5 секунд: жёлтого предупреждения «Обновление применено не
   полностью…» быть НЕ должно. Если появилось — в нём написано, какой именно
   файл на сервере старый: перезалейте папку целиком и повторите.
3. ЛСР → «☷ Столбцы» → закрепить 3 → прокрутка вправо и вниз: шапка всюду
   совпадает с телом, «белых пятен» нет.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4464`).

## Откат

Файлы из архива v4.46.3 + Ctrl+Shift+R. БД не затрагивается.
