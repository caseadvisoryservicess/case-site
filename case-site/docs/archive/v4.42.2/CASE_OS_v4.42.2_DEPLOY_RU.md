# CASE OS v4.42.2 — установка на хостинг (DirectAdmin)

Включает всё из v4.42.0 и v4.42.1 + единые настройки категорий гео-карты.
**SQL-миграций нет, серверные файлы (`os/api/*`) не менялись** — `config.php` не трогаем.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.42.2_os_only.zip` (без секретов: нет `config.php`, баз и бэкапов).
2. В DirectAdmin → File Manager замените содержимое `/os` файлами из архива.
3. Жёсткая перезагрузка: **Ctrl+Shift+R**. В шапке должно быть **v4.42.2**.
4. Если ещё не делали после v4.42.1 — **войдите администратором один раз**
   (миграция шаблонов ролей: лечит «данные не сохраняются» у сотрудников).

## Проверка гео-карты

- У «Бизнес-центров» в шапке слоя — только включатель и ⚙; внутри ⚙ есть «подписи»
  словом, «размер подписи», «подписи с зума», «кластеры точек».
- У «Медицины» и «Аптек» — те же контролы + свои «кластеры точек».
- У метро/коридора/районов все галочки подписаны текстом («подписи станций»,
  «цвет по линии», «цвет по маршруту», «подписи районов»).
