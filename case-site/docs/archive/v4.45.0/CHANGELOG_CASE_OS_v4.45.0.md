# CASE OS v4.45.0 — изменения

Дата: 2026-07-24. Ветка: `claude/new-session-2kq1ff`. Предыдущая версия: v4.44.0.

## 1. Сохранения из карточек сразу видны в таблицах

Закрыт последний источник «надо перегружать страницу»: сохранение из **карточки
помещения** (и всех её действий — правка, объединение, разделение, варианты, отказ,
даты, комментарии, продление КП, переговоры, уточнение площади) обновляло только саму
карточку, а таблица за ней оставалась старой. Теперь текущий экран обновляется сразу,
**с сохранением прокрутки** всех таблиц (`refreshViewKeepScroll`). То же для карточки
бренда (легаси-путь) и цены/статуса продажи в SCR.

## 2. Ширины столбцов можно тянуть и в прилипшей шапке

«Пропала ручная регулировка ширины» — раньше при прокрутке таблицы шапку подменяет
прилипший клон, а в клоне резайзеры были спрятаны (регулировать было нечем; до v4.43.2
выручал баг с «полоской» во всю высоту). Теперь резайзеры в прилипшей шапке видимы и
работают: перетаскивание пробрасывается настоящей таблице, клон подстраивается по ходу.

## 3. Единый вид таблиц по эталону «Управление геоданными»

По вашему выбору эталона: LCR, База брендов и все остальные таблицы платформы получили
вид гео-таблицы — просторные строки 40px, отступы 9×10, приглушённые заголовки на
светлом фоне, подсветка строки под курсором, счётчик над таблицей в гео-стиле
(«Показано N строк · M столбцов»). Плотность по умолчанию — «комфортная» (как в гео);
личный выбор плотности каждого пользователя сохраняется и синхронизируется между
устройствами (v4.43.0).
