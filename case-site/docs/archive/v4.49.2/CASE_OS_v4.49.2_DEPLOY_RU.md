# CASE OS v4.49.2 — установка на хостинг (DirectAdmin)

Варианты брендов больше не теряются при подборе; справочник категорий расширен втрое.
Подробности — `CHANGELOG_CASE_OS_v4.49.2.md`.

## Шаг 1. Файлы

Замените ВСЁ содержимое папки `/os` содержимым архива `CASE_OS_v4.49.2_os_only.zip`
(с перезаписью). `api/config.php` не затрагивается, серверные PHP не менялись.

## Шаг 2. Проверка (2 минуты)

1. Ctrl+Shift+R → в шапке **v4.49.2**, жёлтого предупреждения нет.
2. ЛСР → «Правка» → в столбце «Варианты» у помещения с несколькими брендами выберите
   ещё один бренд из подсказки: платформа предложит ДОБАВИТЬ его к прежним, а не заменить.
3. База брендов → карточка бренда → «Категория: Услуги и сервисы» → в «Подкатегории»
   начните вводить «Поли» — появится «Полиграфия / печать».

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4492`).

## Откат

Файлы из архива v4.49.1 + Ctrl+Shift+R. БД не затрагивается.
