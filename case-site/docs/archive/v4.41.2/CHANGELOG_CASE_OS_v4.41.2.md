# CASE OS v4.41.2 — Changelog

Дата релиза: 24 июля 2026 г. Включает всё из v4.41.0/4.41.1.

## Исправлена регрессия доступа роли «Младший админ брендов» (BRJ)
- В v4.35.0 в меню был жёстко зашит фильтр «BRJ видит только Базу брендов» (восстановление
  старого правила ядра). Он перекрывал НАСТРАИВАЕМОЕ рабочее пространство роли: у BRJ
  по умолчанию есть гео-аналитика и рынок, а админ может расширять набор. В результате
  у роли пропали гео/бренды из меню (вплоть до пустого меню при кастомном наборе).
- Фильтр удалён: видимость разделов BRJ определяет только workspace (как у всех ролей).
  Проверено: меню BRJ в демо — dash, проекты, задачи, Kanban, LCR, бренды, гео.
- Ролевой тест обновлён: «меню по workspace — есть бренды, нет админ-экранов».
