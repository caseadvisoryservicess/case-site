# CASE OS v4.47.0 — установка на хостинг (DirectAdmin)

Пересборка табличного ядра: вся шапка/закрепление/прилипание — в одном модуле,
плюс страховка от старых файлов на сервере. Подробности —
`CHANGELOG_CASE_OS_v4.47.0.md`.

## Шаг 1. Файлы — залить ЦЕЛИКОМ

Замените ВСЁ содержимое папки `/os` содержимым архива
`CASE_OS_v4.47.0_os_only.zip`. `api/config.php` в архиве нет — конфиг не
затрагивается. Серверные PHP не менялись (при обновлении с v4.45.x — один раз
войдите администратором после заливки).

## Шаг 2. Проверка (3 минуты)

1. Ctrl+Shift+R → в шапке **v4.47.0**.
2. В течение 5 секунд НЕТ жёлтого предупреждения про старые файлы (если есть —
   в нём имя файла, который не заменился: перезалейте папку целиком).
3. ЛСР → «☷ Столбцы» → закрепить 3–4 → прокрутка вправо и вниз: шапка (обе
   строки) везде совпадает с телом, белых пятен нет.
4. Сохраните правку из карточки: таблица обновляется сразу, позиция цела.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4470`).

## Откат

Файлы из архива v4.46.4 + Ctrl+Shift+R. БД не затрагивается.
