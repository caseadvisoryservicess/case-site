# CASE OS v4.32.0 — Staging Acceptance Checklist

## A. Развёртывание и кэш

- [ ] Создан backup файлов и базы данных текущей production-версии.
- [ ] v4.32.0 сначала установлена на staging.
- [ ] В верхней панели отображается `v4.32.0`.
- [ ] В DevTools отсутствует загрузка старых `?v=4.31.x` или `?v=4.17.0` скриптов.
- [ ] Service Worker использует cache `case-os-v4320`.
- [ ] После hard refresh открывается новая версия.
- [ ] `v432-data-grid.js` загружается без 404.

## B. База брендов

- [ ] Возле сортируемых заголовков виден `↕`.
- [ ] Первый клик сортирует по возрастанию.
- [ ] Второй клик сортирует по убыванию.
- [ ] Третий клик убирает сортировку.
- [ ] `▾` открывает меню фильтра.
- [ ] Работает поиск внутри списка значений.
- [ ] Работают text conditions.
- [ ] Работают numeric conditions для min/max площади.
- [ ] Несколько фильтров применяются одновременно.
- [ ] Фильтр подсвечивается как активный.
- [ ] Меню закрывается по `Esc`.
- [ ] Меню закрывается после перехода в другой раздел.
- [ ] Ширина колонок меняется мышью.
- [ ] Двойной клик по разделителю выполняет auto-fit.
- [ ] После обновления страницы личные настройки остаются.
- [ ] Настройки другого пользователя отличаются.
- [ ] Режимы «Таблица / Список / Карточки» продолжают работать.
- [ ] Импорт и экспорт CSV/XLSX работают.
