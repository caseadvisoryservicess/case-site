# Установка CASE OS v4.32.0

## Рекомендуемый порядок

1. Сделайте полный backup текущего каталога платформы.
2. Сделайте backup MySQL.
3. Разверните v4.32.0 на staging.
4. Пройдите `CASE_OS_v4.32.0_STAGING_ACCEPTANCE_CHECKLIST_RU.md`.
5. После приёмки замените каталог `/os` содержимым нового пакета.
6. Не удаляйте существующий production-каталог до завершения проверки.

## Варианты пакета

### Full Hosting Ready

Содержит:

- сайт;
- каталог `/os`;
- серверные API;
- инструкции;
- changelog;
- отчёты QA.

### OS Only

Содержит только каталог `/os` и предназначен для точечной замены приложения при уже настроенном хостинге.

## После загрузки

1. Убедитесь, что PHP-права на API и data-каталоги сохранены.
2. Откройте платформу в приватном окне.
3. Выполните hard refresh.
4. При необходимости удалите старый Service Worker/cache через DevTools.
5. Проверьте, что отображается `v4.32.0`.
6. В Network убедитесь, что загружается:
   - `v432-data-grid.js?v=4.32.0`;
   - остальные локальные скрипты с `?v=4.32.0`.
7. Проверьте cache name `case-os-v4320`.

## Миграция данных

Для v4.32.0 отдельная миграция MySQL не требуется. Обновление меняет интерфейс и персональные browser preferences.

Корпоративные данные таблиц не переносятся в local preferences.

## Персональные настройки

Новые настройки ширины, порядка, видимости, плотности и фильтров сохраняются в браузере отдельно для каждого пользователя.

При очистке browser storage пользователь потеряет только персональный вид таблиц, но не серверные данные.

## Rollback

1. Верните предыдущий каталог `/os`.
2. Очистите Service Worker cache новой версии.
3. Выполните hard refresh.
4. База данных не требует rollback, если в процессе установки не выполнялись отдельные ручные изменения.

## Важное ограничение

Перед production обязательно проверить v4.32.0 на реальном staging с MySQL, реальными ролями и рабочим доменом Geo Studio.
