# CASE OS v4.43.2 — установка на хостинг (DirectAdmin)

Включает всё из v4.42.x–v4.43.1 + перелёт карты к проекту, переоткрытие отчёта,
устранение «полоски» и шторма перерисовок на LCR.
Серверные файлы в этом релизе не менялись; `config.php` не затрагивается.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.43.2_os_only.zip` (без секретов).
2. Замените содержимое `/os` файлами из архива.
3. Жёсткая перезагрузка: **Ctrl+Shift+R**. В шапке — **v4.43.2**.
4. Если не делали после v4.42.1 — один вход администратором (миграция шаблонов ролей).

## Проверка

1. «Карта объектов» → проект → «Аналитика»: карта перелетает к проекту, отчёт открыт;
   закройте отчёт → клик по маркеру проекта → «🎯 Отчёт по точке» → отчёт снова открыт;
   «⤓ Скачать PDF» — печатная версия полной аналитики.
2. «Контроль аренды (LCR)» → вкладка «План / бюджет»: над таблицей есть панель
   «Таблица · N столбцов · Столбцы · Вид», вертикальной «полоски» посреди таблицы нет,
   ширины столбцов тянутся только за границу заголовка.
