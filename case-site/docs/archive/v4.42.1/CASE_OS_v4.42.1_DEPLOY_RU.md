# CASE OS v4.42.1 — установка на хостинг (DirectAdmin)

Включает всё из v4.42.0 + лечение «данные не сохраняются» у сотрудников.
**SQL-миграций нет, серверные файлы (`os/api/*`) не менялись** — `config.php` не трогаем.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.42.1_os_only.zip` (без секретов: нет `config.php`, баз и бэкапов).
2. В DirectAdmin → File Manager замените содержимое `/os` файлами из архива.
3. Жёсткая перезагрузка: **Ctrl+Shift+R**. В шапке должно быть **v4.42.1**.
4. **Войдите администратором один раз** — миграция дополнит шаблоны всех ролей и сохранится в базе.

## Проверка после обновления

- Под **младшим админом брендов**: изменить запись в «Базе брендов» и точку в геоаналитике →
  обновить страницу → изменения на месте.
- Под **администратором аренды**: правка в ЛСР/реестре → обновить страницу → на месте.
- Если у сотрудника нет прав на раздел, теперь при попытке сохранить появляется явное
  предупреждение «⚠ НЕ сохранено: … — обратитесь к администратору» (раньше — тишина).
- Остальное из v4.42.0: меню на «Версиях планировок», широкие таблицы (включая «Корзину»),
  права ролей в карточке «Доступ ролей и сотрудников», контролы БЦ, мини-тест справа.
