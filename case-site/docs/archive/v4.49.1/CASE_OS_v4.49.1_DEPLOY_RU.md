# CASE OS v4.49.1 — установка на хостинг (DirectAdmin)

Кнопки «Бюджет» и «Факт» теперь сворачивают только свои столбцы.
Подробности — `CHANGELOG_CASE_OS_v4.49.1.md`.

## Шаг 1. Файлы

Замените ВСЁ содержимое папки `/os` содержимым архива `CASE_OS_v4.49.1_os_only.zip`
(с перезаписью). `api/config.php` не затрагивается, серверные PHP не менялись.

## Шаг 2. Проверка (1 минута)

1. Ctrl+Shift+R → в шапке **v4.49.1**, жёлтого предупреждения нет.
2. ЛСР → нажмите «▾ Факт»: сворачиваются только столбцы Факта, остаётся «Итого вкл. обсл.»,
   а «Варианты», «Брокер», «Комментарий» и «Статус» остаются на месте.
3. То же с «▾ Бюджет». Нажмите обе — столбцы сворачиваются, хвост цел.

## Шаг 2б. Если данные уже потерялись — как вернуть

В разделе «Геоаналитика» нажмите **«История / восстановление»**: на сервере хранятся последние
50 снимков геоданных с датой и автором каждого. Администратор может откатить базу к любому
снимку (текущее состояние тоже уйдёт в историю, так что откат обратим).
Если правки делались в том же браузере и не дошли до сервера, там же появится кнопка
**«Восстановить локальную копию»**.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4491`).

## Откат

Файлы из архива v4.49.0 + Ctrl+Shift+R. БД не затрагивается.
