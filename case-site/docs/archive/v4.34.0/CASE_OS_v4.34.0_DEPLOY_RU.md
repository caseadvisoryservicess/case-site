# Установка CASE OS v4.34.0

## Пакет

`CASE_OS_v4.34.0_os_only.zip` — только каталог `/os`, без `config.php`, баз `.sqlite`
и `sql/backups` (доступ к БД и резервные копии на сервере не затираются).

## Перед обновлением

1. Резервная копия текущей папки `/os`.
2. Резервная копия базы данных обычным способом хостинга.

## Установка

1. Распакуйте архив в `domains/caseadvisory.uz/public_html/` (Extract с перезаписью `os/`).
2. SQL-миграции **не требуются**.

## После обновления

1. `https://caseadvisory.uz/os/` → hard reload (Ctrl+Shift+R), в шапке `v4.34.0`.
2. Быстрая проверка UX: слева — развёрнутое меню с подписями (☰ сворачивает);
   на главном — один ряд кликабельных плиток «Центра действий» без служебных текстов;
   баннер «⏰ Внимание: N просроченных дат…» читается полностью;
   мини-тест появляется бейджем 🎓 слева внизу, а не окном поверх работы.

## Откат

Восстановите резервную копию `/os`. Данные БД этим релизом не изменяются.
