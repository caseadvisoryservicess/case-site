# CASE OS v4.34.0 — Changelog

Дата релиза: 24 июля 2026 г.

## Главное: UX-разгрузка («каша» → рабочий инструмент)

Релиз не меняет данные и бизнес-логику — только эргономику интерфейса.

### Навигация: подписи вместо иконок-загадок

- На десктопе левое меню теперь по умолчанию **закреплено в развёрнутом виде**:
  видны названия разделов и заголовки групп («Работа и проекты», «Консалтинг», …),
  а не только ряд безымянных пиктограмм.
- Кнопка ☰ сворачивает меню в узкую рейку (и обратно); выбор запоминается
  в этом браузере. Наведение на рейку по-прежнему раскрывает подписи.
- На мобильных поведение прежнее (выдвижное меню).

### Мини-тест больше не выпрыгивает поверх работы

- Автопоказ вопроса заменён на скромный бейдж 🎓 внизу слева — вопрос
  открывается только по клику. Античит после открытия вопроса работает как раньше.

### Шапка

- Убраны дубли «+ Объект» / «✎ Объект» (эти действия остаются на главном экране
  и в карточке объекта) — освободилось место, селектор проекта больше
  не обрезает название («Creative Avenue · Ташкент» виден целиком).

### Главный экран

- «Центр действий»: один ряд **кликабельных** плиток вместо «плитки + дублирующие
  карточки с теми же числами»; убраны служебный текст «Карточки и кнопки теперь
  ведут…» и устаревшая метка «CASE OS v4.9.3».
- «Комиссии аренды / Поставщики»: убраны английская строка «COMMISSION ENGINES»,
  абзац о приватности (переехал в подсказку) и пустая плитка «Открытые параметры — ASH».
- Англоязычные метки заменены русскими: «Weighted forecast» → «Взвешенный прогноз»
  (EN/UZ-переводы добавлены в словари).

### Планировки

- Кнопка загрузки чертежа сокращена до «⬆ Загрузить чертёж (SVG/PNG)» — блок/этаж
  показываются рядом и в подсказке, а не растягивают кнопку.
- «Прикрепить презентацию (PDF)» понижена до обычной кнопки — не спорит по яркости
  с основным действием экрана.

## Исправленные дефекты

- **Битые баннеры вида «⏰ Внимание: 7⏰ Внимание:»** — `localize()` хранил перевод
  один на элемент и затирал все текстовые узлы после первого в элементах со
  смешанным контентом. Теперь исходник хранится по-узлово (`data-ru`, `data-ru-t1`, …).
  Починены все элементы с «числом внутри текста» на всех языках.
- `v4327-patch.js` больше не откатывает номер версии в шапке к своему
  `PATCH_VERSION` (использует `APP_VERSION`, сохраняет префикс DEMO).

## Технические изменения

- Версия платформы: `4.34.0`; SW cache key: `case-os-v4340`.
- Обновлены с cache-busting: `v32-upgrade.js`, `v326-commission-engines.js`,
  `v3520-workspaces.js`, `v4327-patch.js` (`?v=4.34.0`).
- Новая личная настройка `navPin` (localStorage, в общий блоб не пишется).
- SQL-миграция **не требуется**.
