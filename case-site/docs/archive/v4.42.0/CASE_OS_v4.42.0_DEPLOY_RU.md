# CASE OS v4.42.0 — установка на хостинг (DirectAdmin)

Обновление только клиентских файлов. **SQL-миграций нет, серверные файлы (`os/api/*`) не менялись** —
`config.php` на сервере не трогаем.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.42.0_os_only.zip` (архив без секретов: нет `config.php`, баз и бэкапов).
2. В DirectAdmin → File Manager откройте папку сайта и замените содержимое `/os` файлами из архива
   (`config.php` в `os/api/` останется на месте — в архиве его нет).
3. Откройте сайт и сделайте жёсткую перезагрузку: **Ctrl+Shift+R** (или очистите кэш браузера).
4. Проверьте: в шапке версия **v4.42.0**; в `os/sw.js` ключ кэша `case-os-v4420`.

## Что проверить после обновления

- **Меню**: клик «Версии планировок» — боковое меню не сворачивается.
- **Пользователи**: таблица растянута на всю карточку; отдельной таблицы «Права ролей» нет —
  права настраиваются в карточке «Доступ ролей и сотрудников» (блок «Права на действия»).
- **Младший админ брендов**: войдите администратором один раз (миграция дополнит шаблон роли),
  затем у младшего админа снова видны Реестр, База брендов, Геоаналитика.
- **Гео-студия**: у «Бизнес-центров» появились «размер подписи» и «кластеры точек».
- **Мини-тест**: кнопка 🎓 справа над чатом; на телефоне и у внешних агентов не показывается.
