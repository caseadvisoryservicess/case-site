# CASE OS v4.41.1 — Changelog

Дата релиза: 24 июля 2026 г. Включает всё из v4.41.0 (меню-фикс + гео-категории).

## Чистая консоль браузера (по скриншотам DevTools с прода)
- PWA-манифест: start_url/scope стали абсолютными — предупреждения «URL is invalid» ушли.
- Добавлен современный meta mobile-web-app-capable (деприкейт-предупреждение ушло).
- 404 os/images/layers.png: иконка контрола слоёв Leaflet встроена в CSS (SVG data-URI).
- 404 tashkent(_region)_districts.geojson: сначала пробуется локальный os/data/…, затем
  внешние зеркала; при неудаче слой тихо пропускается ОДИН раз (без спама 404),
  файл можно положить в os/data/ и он подхватится.
- «Yandex Maps: Invalid API key» — это настройка, не код: Карта объектов → блок ключа
  Яндекс.Карт (админ) — вставьте действующий ключ или очистите поле.
