# CASE OS v4.47.1 — установка на хостинг (DirectAdmin)

Фикс: линии прилипшей шапки совпадают с телом таблицы попиксельно.
Подробности — `CHANGELOG_CASE_OS_v4.47.1.md`.

## Шаг 1. Файлы

Замените ВСЁ содержимое папки `/os` содержимым архива
`CASE_OS_v4.47.1_os_only.zip`. `api/config.php` не затрагивается.
Серверные PHP не менялись.

## Шаг 2. Проверка (2 минуты)

1. Ctrl+Shift+R → в шапке **v4.47.1**, жёлтого предупреждения о старых файлах нет.
2. ЛСР → закрепите столбцы → прокрутите вниз (шапка прилипла) и вправо:
   каждая вертикальная линия шапки продолжается в теле без смещения.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4471`).

## Откат
