# CASE OS v4.48.0 — установка на хостинг (DirectAdmin)

Клон-копия шапки удалена: прилипает настоящая шапка таблицы, разойтись с телом
она не может физически. Подробности — `CHANGELOG_CASE_OS_v4.48.0.md`.

## Шаг 1. Файлы — залить ЦЕЛИКОМ

Замените ВСЁ содержимое папки `/os` содержимым архива
`CASE_OS_v4.48.0_os_only.zip`. `api/config.php` не затрагивается.
Серверные PHP не менялись.

## Шаг 2. Проверка (2 минуты)

1. Ctrl+Shift+R → в шапке **v4.48.0**, жёлтого предупреждения о старых файлах нет.
2. ЛСР: строки теперь прокручиваются внутри таблицы (у таблицы своя высота
   по экрану) — шапка всегда видна.
3. Закрепите 3–4 столбца → крутите вниз, вправо, поменяйте масштаб браузера:
   шапка всегда идёт с телом, линия в линию, белых пятен нет.
4. Потяните ширину столбца прямо в прилипшей шапке — работает.
