# CASE OS v4.50.4 — установка

Включает v4.50.1–v4.50.3. Миграций базы нет, серверные PHP не менялись.

## Коротко

1. Скачайте `CASE_OS_v4.50.4_os_only.zip`.
2. DirectAdmin → Менеджер файлов → `domains/caseadvisory.uz/public_html/`.
3. Распакуйте с **перезаписью** папки `os`.
4. `Ctrl+Shift+R`. В шапке должно быть **v4.50.4**.

## Что изменилось

Поле «Тип» в форме бренда было пустым — и не для одной категории, а **для всех
шестнадцати**. Причина в том, что справочник типов остался на названиях категорий,
которые действовали до обновления таксономии, и вдобавок не выставлялся наружу.

«Оператор связи» при этом в системе был — просто до него нельзя было добраться.
Теперь он есть и в подкатегориях («Оператор связи / салон связи»), и в типах.

Заодно вернулась галочка алкоголя: она не появлялась даже у ресторанов и супермаркетов,
то есть ровно там, где нужна.

## Проверка после установки

Бренды → добавить бренд → категория «Услуги и сервисы». В поле «Подкатегория» должен
быть пункт **«Оператор связи / салон связи»**, в поле «Тип» — 11 пунктов, среди них
**«Оператор связи»**.

Для проверки алкоголя выберите категорию «F&B / рестораны и кафе» — должна появиться
галочка алкоголя.

Записи, где раньше стояло «Telecom», не потеряются: старое название оставлено
псевдонимом и распознаётся по-прежнему.
