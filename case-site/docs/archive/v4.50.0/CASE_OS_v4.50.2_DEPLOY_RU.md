# CASE OS v4.50.2 — установка

Включает всё из v4.50.1 — её отдельно ставить не нужно.

## Коротко

1. Скачайте `CASE_OS_v4.50.2_os_only.zip`.
2. DirectAdmin → Менеджер файлов → `domains/caseadvisory.uz/public_html/`.
3. Распакуйте с **перезаписью** папки `os`.
4. `Ctrl+Shift+R`. В шапке должно быть **v4.50.2**.

Архив содержит только папку `os`, без `config.php` — доступ к базе не затрагивается.

## Что изменилось

Изменены `os/index.html`, `os/v4327-patch.js`, `os/quiz-data.js`, `os/sw.js`.
Ядро `core.js` не менялось и останется в кэше браузера. Серверные PHP не трогали,
миграций базы нет.

**Мини-тест больше не выдаёт правильный ответ.** В вариантах стояли приписки
(«— рабочий вариант», «— в рамках процедуры» и ещё три), и они были только
у неверных ответов — ни одной у верного за все 1000 вопросов. Убраны во всех
трёх языках.

**Отклонённая правка помещения возвращается к прежнему значению.** Раньше она
оставалась на экране как сохранённая, и сотрудник узнавал о потере только после
обновления страницы.

## Важно про Асада (роль «Младший админ брендов»)

При правке реестра он увидит:

> ⛔ Сервер отклонил правку помещения: Для этой роли LCR доступен только для просмотра.
> Значение возвращено к прежнему — сообщите администратору.

Это не поломка, а честное отражение прав: сервер закрывает правку помещений для
ролей `AGX`, `BSH` и `BRJ`. Запрет был тот же и раньше, просто выглядел как пропажа данных.

Решение за вами: оставить как есть (могу убрать у него кнопки правки, чтобы не пробовал)
или дать роли право править реестр — тогда он получит доступ к ставкам и бюджетам
всех помещений.

## Проверка после установки

Откройте мини-тест: в вариантах ответов не должно быть хвостов вида
«— рабочий вариант». Через день работы:

```bash
cd ~/domains/caseadvisory.uz/public_html/os
php deep_check.php
```
