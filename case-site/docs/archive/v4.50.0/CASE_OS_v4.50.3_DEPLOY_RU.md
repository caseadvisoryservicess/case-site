# CASE OS v4.50.3 — установка

Выпуск по итогам внешнего аудита пакета v4.50.2. Включает v4.50.1 и v4.50.2.

## Коротко

1. Скачайте `CASE_OS_v4.50.3_os_only.zip`.
2. DirectAdmin → Менеджер файлов → `domains/caseadvisory.uz/public_html/`.
3. Распакуйте с **перезаписью** папки `os`.
4. `Ctrl+Shift+R`. В шапке должно быть **v4.50.3**.

Архив содержит только папку `os`, без `config.php`. Миграций базы нет.

## Главное изменение: резервные копии переезжают

Раньше дампы базы лежали в `os/sql/backups`, то есть внутри публичной папки, а
имена у них предсказуемы с точностью до секунды. Кто угадывал имя — скачивал всю
базу по прямой ссылке, минуя вход и проверку прав.

После установки копии складываются **выше публичной папки**:

```
~/domains/caseadvisory.uz/caseos_backups/
```

Семь уже сделанных копий переедут туда автоматически, когда вы первый раз
откроете раздел бэкапов. Список и восстановление работают как раньше.

### Проверьте после установки

Откройте в браузере адрес любой старой копии, например:

```
https://caseadvisory.uz/os/sql/install_all.sql
```

Должно отдать **403 Forbidden**. Если файл скачивается — значит хостинг игнорирует
`.htaccess`, напишите мне, сделаем иначе.

## Остальное в этом выпуске

- Выгрузка в PPTX больше не блокируется собственной политикой безопасности сайта.
  Шрифты Google тоже разрешены явно.
- Если сервер вдруг перестанет выполнять PHP, платформа честно скажет, что сервер
  недоступен, вместо показа нерабочего входа.
- Мини-тест добавлен в офлайн-кэш.
- Мелочи: подсказка «?» стала удобнее для пальца, план `zarafshan-l2.svg` починен.

Геоаналитика не открывается в демо-режиме — она всегда спрашивает разрешение
у настоящего сервера. Это следствие защиты, которую мы ставили специально, поэтому
самовольно ослаблять её я не стал. Нужно ваше решение — см. `CHANGELOG_CASE_OS_v4.50.3.md`.
