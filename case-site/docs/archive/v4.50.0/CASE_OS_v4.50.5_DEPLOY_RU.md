# CASE OS v4.50.5 — установка

Включает v4.50.1–v4.50.4. Миграций базы нет.

## Коротко

1. Скачайте `CASE_OS_v4.50.5_os_only.zip`.
2. DirectAdmin → Менеджер файлов → `domains/caseadvisory.uz/public_html/`.
3. Распакуйте с **перезаписью** папки `os`.
4. `Ctrl+Shift+R`. В шапке должно быть **v4.50.5**.

Изменены `os/index.html`, `os/core.js`, `os/sw.js` и `os/api/state.php`.

## Что изменилось

Сообщение «НЕ сохранено: USERS, Бенчмарки, ROLES…» больше не появляется.

Важно понимать: **правки сохранялись и раньше**. Сервер записывает разделы по
отдельности — доступные роли сохраняет, закрытые возвращает как были. В предупреждении
перечислялись разделы, которых сотрудник не касался: клиент отправлял по ним свои
встроенные заготовки, а сервер их не принимал. Теперь клиент их просто не отправляет.

## Один вопрос к вам

В списке был раздел **«Бенчмарки»**. Если сотрудник правил именно эту таблицу — вот
она действительно не сохранялась: раздел закрыт для его роли на сервере, хотя
интерфейс правку позволяет.

Уточните, какую таблицу он редактировал. Если бенчмарки — скажите, открыть роли этот
раздел или убрать у неё редактирование, чтобы не вводило в заблуждение.
