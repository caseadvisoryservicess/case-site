# CASE OS v4.48.4 — установка на хостинг (DirectAdmin)

Кнопки в Базе брендов на телефоне доведены до нормального размера + добавлен внутренний
инструмент поиска конфликтов стилей. Подробности — `CHANGELOG_CASE_OS_v4.48.4.md`.

## Шаг 1. Файлы — залить ЦЕЛИКОМ

Замените ВСЁ содержимое папки `/os` содержимым архива
`CASE_OS_v4.48.4_os_only.zip`. `api/config.php` не затрагивается. Серверные PHP не менялись.

## Шаг 2. Проверка (1 минута)

1. Ctrl+Shift+R → в шапке **v4.48.4**, жёлтого предупреждения о старых файлах нет.
2. Откройте **Базу брендов с телефона**: кнопки над списком («+ Добавить бренд»,
   «Импорт CSV/XLSX») стали выше и удобнее нажимаются пальцем.
3. Остальное без изменений — таблицы, закрепление, шапка работают как в v4.48.3.

## Шаг 3. Сотрудникам
