# CASE OS v4.32.3 — Changelog

Дата сборки: 2026-07-23  
Тип релиза: patch — исправления сохранения, прав, UX таблиц и поведения редакторов.

## 1. Сохранение LCR / SCR

- Добавлен атомарный endpoint `api/unit_patch.php` для изменения одного помещения без перезаписи всего общего состояния платформы.
- Добавлен атомарный endpoint `api/units_batch.php` для структурных операций: создание, удаление, объединение, разделение, массовая перенумерация и другие пакетные изменения юнитов.
- Клиентский патч перехватывает основные изменения LCR/SCR и отправляет только изменённые юниты.
- Пока атомарная запись не подтверждена сервером, автообновление общего state считается занятым и не должно затирать локальную правку.
- При временном сбое сервера правка сохраняется локально и автоматически повторяется после восстановления связи.
- Общий `state.php` дополнительно защищает атомарно обновлённые юниты от старой вкладки с устаревшим `updatedAt`.

## 2. Таблицы LCR, SCR и геоданных

- LCR визуально приведён ближе к эталонной базе брендов: более читаемые строки, заголовки, границы, hover и компактная панель вида.
- Геотаблица растягивается на всю доступную ширину, получила более читаемые строки и заголовки.
- Убраны дублирующие нижние строки фильтров в LCR, SCR, базе брендов и геоданных.
- Сохранён единый Excel-подобный фильтр в заголовке столбца.
- Добавлены компактные чипы активных фильтров для таблиц общего движка с удалением отдельного фильтра и кнопкой «Очистить все».
- Сохранены изменение ширины колонок, auto-fit, закрепление и личные настройки пользователя.

## 3. Брокер в LCR

- Обычный клик по строке больше не должен случайно оставлять встроенный select открытым.
- Поле брокера заменяется на явную кнопку редактирования.
- Список брокеров закрывается после выбора, по клику вне списка, по `Esc` и при открытии другого списка.
- Выбор брокера сохраняется атомарно.

## 4. Внешний агент AGX

- Исправлена подпись роли: вместо ошибочного «Генеральный директор» отображается «Внешний агент».
- AGX переведён в fail-closed режим и не получает общие права `edit`, `finance`, `admin` или прямой доступ к LCR/SCR.
- База брендов: доступна только сокращённая форма отправки нового бренда на внутреннюю проверку.
- Инвесторы: доступна только сокращённая форма отправки нового инвестора на внутреннюю проверку.
- Скрыты существующие записи, контакты, ответственные, внутренние комментарии, редактирование, массовые операции, импорт, экспорт, скачивание и backup-кнопки.
- `state.php` не отдаёт AGX базы брендов, инвесторов, продаж, комиссий, документы и юниты.
- Универсальный `data.php` блокирует просмотр чувствительных таблиц и все generic POST-изменения AGX.
- Добавлена SQL-миграция `2026_07_23_v4322_agx_lockdown.sql` для существующих инсталляций.

## 5. Что намеренно не включено

Полноценный Центр доступа, выдача внешнему агенту конкретного проекта/юнита, запросы на юниты, сроки закрепления и согласование КП/LOI/договора запланированы отдельным функциональным релизом v4.33.0. В v4.32.3 внешний агент не получает LCR/SCR до появления этой серверной модели.
