# CASE OS v4.49.0 — установка на хостинг (DirectAdmin)

Страница платформы стала легче в 18 раз (1004 КБ → 56 КБ): код ядра вынесен в отдельный файл.
Подробности — `CHANGELOG_CASE_OS_v4.49.0.md`.

## ⚠ Главное отличие этого релиза

В архиве появился **НОВЫЙ файл `os/core.js`** — это код платформы, вынесенный из `index.html`.
**Без него сайт не откроется вообще** (будет пустая страница). Поэтому заливать нужно
**весь архив целиком, с перезаписью папки** — как обычно через Менеджер файлов → Extract.
Не заливайте отдельные файлы выборочно.

## Шаг 1. Файлы

1. Загрузите `CASE_OS_v4.49.0_os_only.zip` в `domains/caseadvisory.uz/public_html/`.
2. Extract с перезаписью папки `os/`.
3. Убедитесь, что в папке `os/` появился файл **`core.js`** (~950 КБ).

`api/config.php` не затрагивается, серверные PHP не менялись.

## Шаг 2. Проверка (2 минуты)

1. Ctrl+Shift+R → в шапке **v4.49.0**.
2. Жёлтого предупреждения о старых файлах быть не должно.
3. Откройте ЛСР, Базу брендов, Геоаналитику — всё работает как раньше.
4. Если страница пустая — значит `core.js` не залился: перезалейте архив целиком.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4490`). Начиная со **следующего** обновления они
почувствуют разницу: страница будет догружаться быстрее, потому что ядро возьмётся из кэша.

## Откат

Файлы из архива v4.48.4 + Ctrl+Shift+R. В той версии `core.js` не нужен, лишний файл в папке
не мешает. БД не затрагивается.
