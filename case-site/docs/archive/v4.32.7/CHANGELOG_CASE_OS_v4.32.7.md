# CASE OS v4.32.7 — Changelog

Дата релиза: 23 июля 2026 г.

## Исправлено

### Двухуровневая шапка LCR/SCR

- Строки групп `БЮДЖЕТ / ФАКТ` и названий колонок теперь закрепляются как единый блок.
- Нижняя строка больше не уходит под верхнюю и не обрезается при вертикальной прокрутке.
- Высота групповой строки измеряется фактически, а не задаётся предположением.
- Закреплённая шапка учитывает реальную высоту верхней панели CASE OS.
- При изменении высоты верхней панели позиция шапки пересчитывается автоматически.

### Передача вертикальной прокрутки странице

- Устранена «ловушка прокрутки» внутри LCR/SCR и других таблиц с собственным вертикальным скроллом.
- Когда внутренняя таблица достигла верхней границы, дальнейшая прокрутка вверх продолжает прокрутку страницы до шапки проекта.
- Аналогично при достижении нижней границы дальнейшая прокрутка вниз передаётся родительскому контейнеру или странице.
- Горизонтальная прокрутка таблицы при этом не блокируется.

### Горизонтальная синхронизация

- Закреплённая копия шапки синхронизируется с `scrollLeft` таблицы.
- Заголовки остаются над соответствующими колонками при горизонтальном перемещении.
- Фильтры в закреплённой шапке открывают меню исходного столбца.

## Технические изменения

- Версия платформы: `4.32.7`.
- Service Worker cache key: `case-os-v4327`.
- Подключён `v4327-patch.js?v=4.32.7`.
- `CASE Data Grid` обновлён до `4.32.7`.
- SQL-миграция не требуется.

## Совместимость

Исправление не меняет данные LCR, SCR, брендов, сделок, ставок, планировок или прав пользователей. Изменяется только поведение шапок и прокрутки таблиц.
