# CASE OS v4.36.0 — Changelog

Дата релиза: 24 июля 2026 г.

## Платформа теперь и в `main`

Ветка `main` репозитория доведена до состояния платформы (раньше там был только
маркетинговый лендинг, вся платформа жила в рабочей ветке — случайное удаление
ветки означало потерю всего). Рабочая ветка остаётся основной для разработки.

## Автобэкап БД — готовая инструкция

- Новый документ **`docs/ops/АВТОБЭКАП_И_CRON_ПОШАГОВО.md`**: настройка ежедневного
  автобэкапа через встроенный `os/api/backup.php` (cron-токен в `config.php`,
  cron-задача в DirectAdmin, проверка, ротация 30 дней, копия вне сервера) +
  настройка почтовых уведомлений о критичных датах (`cron_critical_dates.php`, SMTP).
  Код бэкапа уже был в платформе — не хватало только настройки на хостинге.

## Мобильная эргономика

- Плитки «Центра действий» на телефоне — 2 колонки вместо длинного столбца
  (главный экран стал вдвое короче).
- Ряды табов (`.tabs`, гео-таббары) на мобильных — одна строка с горизонтальным
  свайпом: кнопки больше не переносятся по пол-слова и не съедают экран.
- Проверено скриншотами на вьюпорте 390×844: шапка, меню (группы+подписи),
  главный, LCR, планировки, бренды.

## Технические изменения

- Версия платформы: `4.36.0`; SW cache key: `case-os-v4360`; `v32-upgrade.js?v=4.36.0`.
- SQL-миграция **не требуется**; серверные файлы не менялись.
