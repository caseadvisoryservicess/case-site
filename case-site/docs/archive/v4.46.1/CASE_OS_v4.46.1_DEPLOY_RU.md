# CASE OS v4.46.1 — установка на хостинг (DirectAdmin)

Релиз вливает ваш v4.45.1 (живая синхронизация без перерисовок) в объединённую
линию v4.46.x. Подробности — `CHANGELOG_CASE_OS_v4.46.1.md`.

## Шаг 1. Файлы

Замените содержимое папки `/os` содержимым архива `CASE_OS_v4.46.1_os_only.zip`.

- В архиве **нет** `api/config.php` — ваш конфиг не затрагивается.
- Новый файл появится сам: `v4451-live-sync.js`.
- Серверные PHP относительно v4.46.0 не менялись. Если на сервере сейчас v4.45.x
  или старше — заливайте всё содержимое архива как есть (в нём уже серверные
  файлы v4.46.0: границы ролей, отчёт собственнику), затем один раз войдите
  администратором (миграция шаблонов ролей 4450).

## Шаг 2. Проверка (3 минуты)

1. В шапке — **v4.46.1** (если нет — Ctrl+Shift+R).
2. ЛСР: прокрутите таблицу вправо, откройте карточку, «✎ Редактировать помещение»,
   измените бюджет, сохраните — значение сразу в таблице, прокрутка на месте.
3. Оставьте ЛСР открытым на 1–2 минуты: экран не «дёргается»; сообщение
   «Данные обновлены» появляется только когда коллега реально что-то изменил.
4. База брендов: сохранение карточки сразу видно в списке, фильтры не сбросились.
5. Геоаналитика: после сохранения локации таблица и карта обновляются, позиция цела.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (обновится кэш `case-os-v4461`).

## Откат

Верните файлы из архива v4.46.0 и Ctrl+Shift+R. БД не затрагивается.
