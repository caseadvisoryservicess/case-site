# CASE OS v4.46.0 — объединённый релиз (мой v4.45.0 + ваш билд FULL_HOSTING_READY)

Дата: 2026-07-25. По запросу «вот мой вариант посмотри его тоже. и собери сам хороший вариант»
оба варианта разобраны по файлам и собраны в один. Ниже — что взято откуда и почему.

## Что взято из ВАШЕГО билда (v4.45.0_FULL_HOSTING_READY)

1. **Отчёт собственнику** — новый модуль `v4450-owner-report.js`:
   - два профиля отчёта: для владельца (без внутренней кухни) и внутренний;
   - вкладки: сводка, площади, бренды, отказы, план, качество данных, версии;
   - кнопка «Отчёт собственнику» появляется в Проектах CASE;
   - снапшоты хранятся в общем состоянии (ключ OWNER_REPORTS), создавать могут
     ASH / CFO / BA / HO;
   - сервер (`state.php`) вычищает из снапшотов приватные поля (брокер, ставки,
     комиссия, контакты собственника, внутренние комментарии) — владелец их не увидит
     даже в сыром JSON.
2. **UX/доступность-слой** — новый модуль `v4450-ux-system.js`:
   - строгий маршрутный гард поверх `go()`: раздел вне прав не открывается даже прямым вызовом;
   - аккуратный экран «Нет доступа» вместо пустого экрана;
   - бейдж «Только просмотр» в реестре для ролей без права правки;
   - a11y-семантика (роли/aria) и адаптивные стили.
3. **Fail-closed модель ролей** (это осознанное решение вашего билда, принято как есть):
   - **Внешний агент (AGX):** только Дашборд, Задачи, Канбан, База брендов, Инвесторы.
   - **Младший админ данных (BRJ):** + Геоаналитика, Данные рынка, Макро, Качество данных,
     Импорт/экспорт; **без ЛСР и без Проектов CASE**. Гео и бренды — полный доступ (жалоба
     закрыта ещё в v4.42.0, здесь сохранено).
   - **Архитектор (BSH):** дефолтные разделы + ЛСР **только для просмотра**.
   - Сервер (`lib.php`) режет лишние разделы жёстко (`asaas_workspace_hard_allowed`),
     `unit_patch.php`/`units_batch.php` отвечают 403 этим ролям — правка ЛСР невозможна
     даже в обход интерфейса.
   - Клиент: миграция шаблонов ролей до схемы **4450** — сначала объединение с дефолтами
     (ничего из положенного не теряется), затем fail-closed обрезка лишнего, включая
     сохранённые пользовательские рабочие среды.

## Что сохранено из МОЕГО v4.45.0 (в вашем билде этого не было)

1. **Надёжность сохранений (v4.44.0)** — корень жалоб «данные не сохраняются»:
   серверная сессия 12 часов, keepalive-пинг каждые 5 минут, экран входа со счётчиком
   несохранённых правок, автоматическая дозаливка очереди после повторного входа,
   честные ошибки 401/403 вместо тихой потери.
2. **Правки видны сразу** — refreshViewKeepScroll() для всего карточного семейства +
   точечный пересчёт строк ЛСР (v4.43.3), прокрутка и фокус не теряются.
3. **Таблицы**: резайзеры работают и в прилипшей шапке; личные настройки таблиц
   хранятся на сервере per-user (`user_prefs.php`); вид по гео-эталону; один
   горизонтальный ползунок.
4. **Гео**: авто-отчёт по точке при переходе «Аналитика», PDF, перелёт карты,
   переоткрытие отчёта, единые контролы категорий, подписи БЦ/медицины.
