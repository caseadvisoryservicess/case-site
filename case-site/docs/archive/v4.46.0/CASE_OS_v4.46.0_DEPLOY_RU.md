# CASE OS v4.46.0 — установка на хостинг (DirectAdmin)

Объединённый релиз: ваш билд FULL_HOSTING_READY (Отчёт собственнику, строгие права ролей,
UX-слой) + мой v4.45.0 (надёжность сохранений, таблицы, гео). Что и откуда взято —
`CHANGELOG_CASE_OS_v4.46.0.md`.

## Шаг 1. Файлы

Замените содержимое папки `/os` на сервере содержимым архива `CASE_OS_v4.46.0_os_only.zip`.

- В архиве **нет** `api/config.php` — ваш конфиг с паролями БД остаётся на месте, его не трогать.
- **Обновлены серверные файлы** — заливаются вместе со всеми:
  - `api/lib.php` — жёсткие границы ролей + сессия 12 часов;
  - `api/state.php` — Отчёт собственнику + вычистка приватных полей из снапшотов;
  - `api/unit_patch.php`, `api/units_batch.php` — запрет правки ЛСР для AGX/BSH/BRJ (403).
- Новые файлы появятся сами: `v4450-owner-report.js`, `v4450-ux-system.js`.

## Шаг 2. Первый вход

Войдите **администратором** (ASH) — при входе выполнится миграция шаблонов ролей до
схемы 4450. Один раз, дальше автоматически.

## Шаг 3. Проверка (5 минут)

1. В шапке — **v4.46.0** (если нет — Ctrl+Shift+R).
2. **Проекты CASE** → внутри проекта есть кнопка «Отчёт собственнику», отчёт открывается.
3. Под **внешним агентом**: в меню только Дашборд/Задачи/Канбан/Бренды/Инвесторы.
4. Под **младшим админом данных (BRJ)**: гео и бренды открываются и правятся,
   ЛСР и Проектов CASE в меню нет.
5. Под **архитектором (BSH)**: ЛСР виден, бейдж «Только просмотр», правка недоступна.
6. Правка в ЛСР под ASH/HO: сохранение видно в таблице сразу, без перезагрузки.

## Шаг 4. Сотрудникам

Попросите всех сделать **Ctrl+Shift+R** и перезайти (обновится PWA-кэш `case-os-v4460`
и подтянутся новые права).

## Если что-то пошло не так

- Раздел «пропал» у роли — это ожидаемо для AGX/BRJ (см. Шаг 3): границы ролей теперь
  жёсткие и с сервера. Если раздел нужен роли — скажите, расширим список в
  `asaas_workspace_hard_allowed` (lib.php) и в дефолтах v3520.
- Откат: положите обратно файлы из предыдущего архива v4.45.0 и Ctrl+Shift+R.
  БД откатывать не нужно.
