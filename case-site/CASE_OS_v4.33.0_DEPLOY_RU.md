# Установка CASE OS v4.33.0

## Пакет

Для обновления каталога `/os` используйте:

`CASE_OS_v4.33.0_os_only.zip`

Архив не содержит `config.php`, баз `.sqlite` и папки `sql/backups` — доступ к БД
и резервные копии на сервере не затираются.

## Перед обновлением

1. Создайте резервную копию текущей папки `/os`.
2. Создайте резервную копию базы данных обычным способом хостинга.
3. Не удаляйте пользовательские загрузки и серверные конфигурации, если они хранятся отдельно от пакета.

## Установка OS Only

1. Распакуйте `CASE_OS_v4.33.0_os_only.zip` в `domains/caseadvisory.uz/public_html/`
   (Менеджер файлов → Extract, с перезаписью `os/`).
2. Проверьте, что `index.html` загружает `v417-master-plan.js?v=4.33.0`.
3. Проверьте, что `sw.js` содержит cache key `case-os-v4330`.
4. SQL-миграции для этого релиза **не требуются**.

## После обновления

1. Откройте `https://caseadvisory.uz/os/` и сделайте hard reload (Ctrl+Shift+R).
2. Убедитесь, что вверху страницы отображается `v4.33.0`.
3. Быстрая проверка P0-1: выберите проект → «Планировки и LCR» → вкладка «Версии» —
   у версий появилась колонка «Снапшот чертежа»; вкладка «Генерация LCR» — выбор
   версии-источника и её контрольная сумма.

## Откат

Восстановите резервную копию папки `/os`. Данные в БД этим релизом не изменяются.
