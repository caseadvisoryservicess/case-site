# Установка CASE OS v4.32.7

## Рекомендуемый пакет

Для полной замены используйте:

`CASE_OS_v4.32.7_HOSTING_READY_20260723.zip`

Для обновления только каталога `/os` используйте:

`CASE_OS_v4.32.7_os_only.zip`

## Перед обновлением

1. Создайте резервную копию текущей папки `/os`.
2. Создайте резервную копию базы данных обычным способом хостинга.
3. Не удаляйте пользовательские загрузки и серверные конфигурации, если они хранятся отдельно от пакета.

## Установка OS Only

1. Распакуйте `CASE_OS_v4.32.7_os_only.zip`.
2. Замените содержимое действующей папки `/os` содержимым архива.
3. Убедитесь, что на сервере присутствует `v4327-patch.js`.
4. Удалите устаревший `v4326-patch.js`, если он остался после ручного копирования отдельных файлов.
5. Проверьте, что `index.html` загружает:
   - `v432-data-grid.js?v=4.32.7`;
   - `v4327-patch.js?v=4.32.7`.
6. Проверьте, что `sw.js` содержит cache key `case-os-v4327`.

## После обновления

1. Откройте CASE OS.
2. Выполните hard reload: `Ctrl + Shift + R`.
3. При необходимости очистите Service Worker/Application Cache для домена и откройте страницу повторно.
4. Убедитесь, что в интерфейсе отображается `v4.32.7`.
5. Выполните приёмку по отдельному checklist.

## SQL

Новая SQL-миграция не требуется.

## Откат

Для отката восстановите резервную копию предыдущей папки `/os` и выполните hard reload. Данные базы эта версия не преобразует.
