# CASE OS v4.46.3 — установка на хостинг (DirectAdmin)

Фикс закрепления столбцов: шапка прилипает вместе с телом, «белых пятен» нет,
клон шапки согласован. Подробности — `CHANGELOG_CASE_OS_v4.46.3.md`.

## Шаг 1. Файлы

Замените содержимое папки `/os` содержимым архива `CASE_OS_v4.46.3_os_only.zip`.
`api/config.php` в архиве нет — конфиг не затрагивается. Серверные PHP не менялись
(относительно v4.46.0); при обновлении с v4.45.x — заливайте целиком и один раз
войдите администратором.

## Шаг 2. Проверка (2 минуты)

1. В шапке — **v4.46.3** (иначе Ctrl+Shift+R).
2. ЛСР → «☷ Столбцы» → «Закрепить первых видимых столбцов: 3» → Применить.
3. Прокрутите таблицу вправо: первые 3 столбца стоят на месте ВМЕСТЕ с их
   заголовками, белых пятен нет.
4. Прокрутите вниз (шапка прилипла сверху) и снова вправо: закреплённые столбцы
   в прилипшей шапке тоже стоят, остальные едут синхронно с телом.

## Шаг 3. Сотрудникам

Ctrl+Shift+R один раз (кэш `case-os-v4463`).

## Откат

Файлы из архива v4.46.2 + Ctrl+Shift+R. БД не затрагивается.
