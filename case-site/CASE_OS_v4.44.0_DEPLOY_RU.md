# CASE OS v4.44.0 — установка на хостинг (DirectAdmin)

Ключевой релиз надёжности: закрыт корень «данные не сохраняются» (сессия жила 1 час).
**Обновлён серверный файл `os/api/lib.php`** — он в архиве и копируется вместе со всеми;
`config.php` не затрагивается, SQL вручную не нужен.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.44.0_os_only.zip` (без секретов).
2. Замените содержимое `/os` файлами из архива.
3. Жёсткая перезагрузка: **Ctrl+Shift+R**. В шапке — **v4.44.0**.
4. Если не делали после v4.42.1 — один вход администратором (миграция шаблонов ролей).
5. Попросите сотрудников тоже сделать Ctrl+Shift+R и перезайти.

## Что изменится для сотрудников

- Сессия держится весь рабочий день (12 ч + продление при работе) — «внезапный выход»
  посреди дня уходит.
- Если сессия всё же истекла: экран входа появляется сразу, с сообщением
  «несохранённые правки (N) будут отправлены автоматически» — после входа правки
  дозаливаются сами, ничего не теряется.
- Если сервер отклонил правку из-за прав — теперь это видно сразу (красное сообщение),
  а не выглядит как «сохранилось».
- Над таблицами — одна полоса горизонтальной прокрутки вместо двух.
