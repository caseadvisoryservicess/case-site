# Установка CASE OS v4.35.0

## Пакет

`CASE_OS_v4.35.0_os_only.zip` — только каталог `/os`, без `config.php`, баз `.sqlite`
и `sql/backups`. **Внимание: в этом релизе обновлены и серверные файлы**
(`api/state.php`, `api/lib.php`, `api/geo_collector.php`, `api/geo_seed_convert.php`,
`.htaccess`) — распаковывайте с перезаписью всей папки `os/`, включая `os/api/`
(ваш `os/api/config.php` в архиве отсутствует и не будет затёрт).

## Перед обновлением

1. Резервная копия текущей папки `/os`.
2. Резервная копия базы данных обычным способом хостинга.

## Установка

1. Распакуйте архив в `domains/caseadvisory.uz/public_html/` (Extract с перезаписью `os/`).
2. SQL-миграции **не требуются**.

## После обновления

1. `https://caseadvisory.uz/os/` → hard reload (Ctrl+Shift+R), в шапке `v4.35.0`.
2. Проверьте вход и сохранение любой правки (новые доменные сохранения + авто-слияние
   конфликтов): правка в двух вкладках параллельно должна объединяться с тостом
   «↻ Данные менялись параллельно — объединено и сохранено».
3. Проверка защиты LCR: «Планировки и LCR» → «Генерация LCR» — защищённые юниты
   разрешаются только по одному, с обязательной причиной.
4. Если что-то визуально сломалось после обновления — проверьте новые CSP-заголовки
   в `os/.htaccess` (секция `Content-Security-Policy`): сообщите, что именно
   блокируется (консоль браузера, ошибки «Refused to …»).
5. Прямой веб-запрос к `os/api/geo_collector.php` теперь должен отвечать `403 CLI only`.

## Откат

Восстановите резервную копию `/os`. Данные БД этим релизом не изменяются.
