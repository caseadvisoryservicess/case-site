# CASE OS v4.43.1 — установка на хостинг (DirectAdmin)

Включает всё из v4.42.x и v4.43.0 + авто-отчёт по проекту и PDF в геоаналитике.
Серверные файлы в ЭТОМ релизе не менялись (api/user_prefs.php появился в v4.43.0 и
входит в архив). `config.php` не затрагивается, SQL вручную не нужен.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.43.1_os_only.zip` (без секретов).
2. Замените содержимое `/os` файлами из архива.
3. Жёсткая перезагрузка: **Ctrl+Shift+R**. В шапке — **v4.43.1**.
4. Если не делали после v4.42.1 — один вход администратором (миграция шаблонов ролей).

## Проверка

1. «Карта объектов» → выберите проект → «Аналитика»: геоаналитика откроется с точкой
   проекта И сразу с открытым «Отчётом по точке» (кликать по карте не нужно).
2. В отчёте нажмите «⤓ Скачать PDF» — откроется печатная версия с полной аналитикой
   локации и диалог печати; выберите «Сохранить как PDF».
   Если браузер блокирует всплывающие окна — разрешите их для сайта.
