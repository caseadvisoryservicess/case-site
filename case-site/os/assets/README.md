# Изображения для документов CASE OS

## Титульный лист коммерческого предложения

Модуль `v4690-offer-cover.js` берёт картинку в таком порядке:

1. фото самого проекта, если оно приложено к предложению;
2. одна из стандартных картинок из этой папки - какая именно, определяет номер
   предложения, поэтому один документ при каждой печати выглядит одинаково, а соседние
   номера чередуются;
3. блок из цифр опыта, если стандартных картинок нет.

Ожидаемые файлы:

| Файл | Что на нём |
|---|---|
| `offer-cover-1.jpg` | интерьер галереи торгового центра |
| `offer-cover-2.jpg` | авторский эскиз фасада |

Требования: горизонтальная или квадратная ориентация, короткая сторона от 1200 px,
без надписей и водяных знаков поверх изображения, права на использование подтверждены.
Формат `.jpg`; если кладёте `.png` или `.webp`, поправьте расширения в списке `STOCK`
модуля `v4690-offer-cover.js`.

Пока файлов нет, титул собирает блок из цифр - пустой рамки в клиентском документе
не появится ни при каких условиях, это прямое требование технического задания.

Список картинок можно расширять: добавьте файл сюда и строку в `STOCK`, чередование
подхватит его само.
