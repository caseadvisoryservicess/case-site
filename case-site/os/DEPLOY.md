# CASE OS v4.77.0 - краткая установка

Дорожная карта владельца целиком: махалли по районам с населением и его структурой,
демография с трендом и прогнозом на десять лет во всей аналитике, сторона дороги по типу
проекта, профили пользователей и «Что рядом», публичная оферта с согласием, личный кабинет,
обратная связь и Telegram-бот. Что вошло: `CHANGELOG_CASE_OS_v4.77.0.md` в корне пакета.

1. Замените всё содержимое папки `/os` содержимым архива. `api/config.php` в архиве нет
   намеренно: ваш рабочий файл остаётся как есть (сохраните копию, если меняете папку целиком).
   Файлы, начинающиеся с точки (`.htaccess`, `api/.htaccess`, `api/.user.ini`), обязательны.
2. Ctrl+Shift+R. В шапке `v4.77.0`.
3. База: таблица обращений `feedback` создаётся сама при первом обращении к `api/feedback.php`;
   отдельной миграции нет. Миграция v4.76.0 (`2026_09_17_v4760_access.sql`), если ещё не
   применена: «Доступ» → «Обновление базы данных» → «Применить миграции».
4. Новые файлы: `v4770-geo-mahalla.js`, `v4770-geo-roadside.js`, `v4770-geo-profiles.js`,
   `v4770-cabinet.js`, `offer.html`, `api/feedback.php`, `data/demography_tashkent.json`.
   Изменены `index.html`, `sw.js`, `geoanalytics-studio.html`, `v4760-access.js`,
   `api/lib.php`, `api/auth.php`, `api/users.php`, `api/config.sample.php`.
5. Ключи `api/config.php` (необязательные): `'offer_version' => '1.0'` (номер версии оферты;
   при смене номера каждый пользователь подтверждает согласие заново; сам текст в
   `offer.html`), `'feedback_bot_token' => 'длинная случайная строка'` (секрет для
   Telegram-бота из папки `bot/` архива; без ключа приём от бота выключен). Прежние ключи
   `allow_registration`, `demo_login`, `demo_email` работают как раньше.
6. Telegram-бот (по желанию): папка `bot/` архива запускается не на хостинге (PHP там без
   интернета), а на любой машине с Node.js 18+: `bot/README.md`, три переменные в `bot/.env`,
   `node bot/telegram_feedback_bot.js`.
7. Границы махаллей (по желанию, когда будут получены): файл `os/data/mahalla_boundaries.geojson`
   (FeatureCollection, у полигона свойства `name` и `district` в написании студии, например
   `Yunusabad`); студия подхватит его сама и посчитает население махалли внутри границы.

PHP на хостинге 8.0. Код совместим с PHP 7.2-8.4.

Проверка после заливки: в консоли браузера `CASE OS: все модули версии 4.77.0` и, в студии
геоаналитики, `CASE OS: модули гео-студии актуальны`.

Что посмотреть глазами, это и есть смысл выпуска:

1. Студия, раздел «Махалли и демография»: выберите район, список махаллей с населением,
   кружки на карте; кнопка «Демография и рынок»: пирамида, доход, КИПЦ, тренд и прогноз до
   2036 года, допущения и требуемые входные данные; охват меняется списком.
2. Поставьте точку (P), раздел «Сторона дороги»: тип «Бизнес-центр, офисы» → «Определить
   сторону»: отрезок и стрелки на карте, вердикт слева, факт в журнале агента.
3. Переключатель профиля справа на вкладках студии: «Ищу офис» прячет лишние разделы; блок
   «Что рядом» под точкой анализа с метро, остановками, парковками, кафе и т. д.
4. Регистрация: галочка оферты обязательна. Войдите клиентом, который ещё не принимал оферту:
   окно с текстом и галочкой. Меню профиля: «Личный кабинет», «Обратная связь», «Публичная
   оферта»; у администратора «Обращения (N)».
5. «Доступ» (администратор): карточка «Обращения»: просмотрено, ответить, готово; ответ виден
   пользователю в кабинете.

Целостность: `sha256sum -c SHA256SUMS_v4.77.0.txt` из папки `/os`.
