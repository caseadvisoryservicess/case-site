# CASE OS v4.65.0 - краткая установка

Что вошло в релиз: `CHANGELOG_CASE_OS_v4.65.0.md` в корне пакета.
Базовая инструкция по установке и правам: `CASE_OS_v4.51.0_DEPLOY_RU.md` (порядок действий с тех пор не менялся).

1. Замените всё содержимое папки `/os` содержимым архива.
2. Ctrl+Shift+R. В шапке `v4.65.0`.

Изменены `index.html`, `sw.js`, `v492-portfolio-proposals.js`,
`data/case_portfolio.seed.js`, `data/case_portfolio_projects_v4.9.3.json`,
`data/case_portfolio_projects_v4.9.3.csv`, `data/case_portfolio.geojson`.
Миграций базы нет.

Если миграция роли из v4.64.0 ещё не применялась, примените её сейчас:
`sql/migrations/2026_08_13_role_dir.sql`.

Проверка после заливки: в консоли браузера должно быть `CASE OS: все модули версии 4.65.0`,
а при открытой гео-студии - `CASE OS: модули гео-студии актуальны`. Если вместо этого
появилось предупреждение с именами файлов, залита не вся папка `/os`.

Проверка проекта: раздел «Карта проектов Advisory», поиск `Uchtepa` - должен найтись
`Uchtepa Park`, Tashkent, Uzbekistan. Счётчик «точных точек» станет больше на единицу:
у этого проекта координата задана вручную, а не геокодом по городу.

Целостность: `sha256sum -c SHA256SUMS_v4.65.0.txt` из папки `/os`.
Файлы `api/config.php` и `api/config.local*.php` в архив не входят - они ваши,
их не перезаписывают.
