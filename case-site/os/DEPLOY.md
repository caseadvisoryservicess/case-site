# CASE OS v4.46.0 — краткая установка

Полная инструкция находится в корне пакета: `CASE_OS_v4.46.0_DEPLOY_RU.md`.
Обновлены серверные файлы `api/lib.php`, `api/state.php`, `api/unit_patch.php`,
`api/units_batch.php` — копируются вместе со всеми; `config.php` не затрагивается.

1. Замените содержимое папки `/os` содержимым архива `CASE_OS_v4.46.0_os_only.zip`.
2. Войдите один раз администратором — выполнится миграция шаблонов ролей (4450).
3. Проверьте: в шапке `v4.46.0`, в `sw.js` cache key `case-os-v4460`.
4. Попросите сотрудников сделать Ctrl+Shift+R и перезайти.
