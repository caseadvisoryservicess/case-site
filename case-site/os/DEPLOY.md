# CASE OS v4.78.0 - краткая установка

Закрыты пробелы дорожной карты после v4.77.0 (границы махаллей вручную с карты, демография во
всей аналитике и выгрузках, тренд и прогноз для расходов и рынка, «Мои данные» в кабинете,
бесплатный ограниченный доступ «Ищу офис») и встроены данные Ташкента, переданные владельцем:
реестр 585 махаллей с официальными кодами, 402 границы из кадастра (open.ngis.uz), население и
показатели районов, генплан и налоговые зоны в точке, сводка нежилых участков. Что вошло:
`CHANGELOG_CASE_OS_v4.78.0.md` в корне пакета.

1. Замените всё содержимое папки `/os` содержимым архива. `api/config.php` в архиве нет
   намеренно: ваш рабочий файл остаётся как есть (сохраните копию, если меняете папку целиком).
   Файлы, начинающиеся с точки (`.htaccess`, `api/.htaccess`, `api/.user.ini`), обязательны.
2. Ctrl+Shift+R. В шапке `v4.78.0`.
3. База: отдельной миграции нет. Таблица обращений `feedback` создаётся сама. Миграция v4.76.0
   (`2026_09_17_v4760_access.sql`), если ещё не применена: «Доступ» → «Обновление базы данных».
4. Новые файлы: `v4780-geo-ngis.js`, `data/mahalla_registry_tashkent.json`,
   `data/mahalla_boundaries.geojson`, `data/ngis_genplan_tashkent.geojson` (2,9 МБ, грузится
   только по действию пользователя), `data/ngis_nalog_tashkent.geojson`,
   `data/ngis_parcels_tashkent.json`. Изменены `index.html`, `sw.js`, `geoanalytics-studio.html`,
   `v420-geo-studio.js`, `v4530-geo-export.js`, `v4760-geo-caps.js`, `v4770-geo-mahalla.js`,
   `v4770-geo-profiles.js`, `v4760-access.js`, `v4770-cabinet.js`, `data/demography_tashkent.json`,
   `api/lib.php`, `api/auth.php`, `api/users.php`, `api/feedback.php`, `api/config.sample.php`.
   Место на диске: новые данные занимают около 4,2 МБ; на хостинге свободно мало (см. досье,
   раздел 8), перед заливкой удалите старые архивы и бэкапы.
5. Ключи `api/config.php` (необязательные): `'free_office_access' => false` выключает
   бесплатный ограниченный доступ при регистрации с целью «ищу офис» (по умолчанию включён:
   такая учётная запись активна сразу, уровень «free», 40 бизнес-центров, без выгрузки и правок;
   администратор меняет уровень в таблице «Доступ»). Прежние ключи `offer_version`,
   `feedback_bot_token`, `allow_registration`, `demo_login`, `demo_email` работают как раньше.
6. НГИС (open.ngis.uz): запросы уходят из браузера пользователя (сервер CASE OS в интернет не
   ходит). Границы махаллей и генплан работают и без сети: границы 402 махаллей и генплан
   в точке берутся из файлов `data/`; кнопка «Границы махаллей из НГИС» и живой запрос генплана
   нужны только для обновления. Данные публичные, условия коммерческого переиспользования не
   подтверждены: атрибуция в интерфейсе и отчётах оставлена, не убирайте.
7. Обновление данных махаллей (раз в месяц, на машине с интернетом, 20 секунд):
   `python3 docs/data/tashkent_gis_master/refresh_tashkent_gis.py`, затем
   `node docs/qa/tools/ngis_to_studio.js 02_tashkent_mahallas.geojson`; файл
   `os/data/mahalla_boundaries.geojson` заменить на хостинге. Реестр и показатели районов:
   `node docs/qa/tools/build_tashkent_data.js docs/data/tashkent_gis_dataset docs/data/tashkent_gis_master`.

PHP на хостинге 8.0. Код совместим с PHP 7.2-8.4.

Проверка после заливки: в консоли браузера `CASE OS: все модули версии 4.78.0` и, в студии
геоаналитики, `CASE OS: модули гео-студии актуальны`.

Что посмотреть глазами:

1. Студия, «Махалли и демография»: выберите Юнусабадский район: 396 800 жителей, 64 махалли
   реестра, 40 границ кадастра на карте, у строк код, площадь, плотность, участки; кнопка
   «Демография и рынок» по району: факты Toshstat (зарплата, розница, предприятия, миграция),
   тренд по ряду района, три диаграммы, расходы и RDE с прогнозом.
2. Выберите махаллю без границы, нарисуйте полигон инструментом O внизу карты, нажмите
   «▱ из полигона на карте»: население пересчитано внутри границы, полигон пунктиром.
3. Поставьте точку (P): под «Точкой анализа» блок «Генплан и налоговая зона (НГИС)» с функцией
   зоны, этажностью, стратегией; галочка «Зоны генплана на карте»: цветной слой и легенда.
4. Отчёт по точке (кнопка отчёта): разделы «L. Демография и рынок» со строкой «Махалля точки» и
   «M. Генплан Ташкента в точке»; выгрузка Excel: лист «Демография и рынок»; PPTX: слайд.
5. Регистрация: поле «Цель» → «ищу офис»: доступ сразу, ограниченный; в «Доступе» столбец
   «Уровень». Кабинет: карточка «Мои данные» (скачать, очистить).

Целостность: `sha256sum -c SHA256SUMS_v4.78.0.txt` из папки `/os`.
