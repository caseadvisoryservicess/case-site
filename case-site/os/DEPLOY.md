# CASE OS v4.73.1 - краткая установка

Студия геоаналитики без проектов CASE: списка проектов над картой, секции «Проект», точек
портфеля и вкладок про проект больше нет. Вместо них одна точка анализа, которую задаёт
гео-агент (клик по карте, координаты или адрес); по ней считаются отчёт, выгрузка, солнце и
модель Хаффа. Сохранённые гео-профили проектов в базе не трогаются.
Что вошло: `CHANGELOG_CASE_OS_v4.73.1.md` в корне пакета.

1. Замените всё содержимое папки `/os` содержимым архива. `api/config.php` в архиве нет
   намеренно: ваш рабочий файл остаётся как есть (сохраните копию, если меняете папку целиком).
2. Ctrl+Shift+R. В шапке `v4.73.1`.
3. Если v4.73.0 ещё не ставился, он входит сюда целиком: свой гео-агент без внешних ИИ. Тогда
   удалите из `os/api/config.php` строку `'anthropic_api_key' => ...` (она больше не читается)
   и, если копировали поверх, а не заменяли папку, три файла v4.72.0: `os/v4720-geo-assistant.js`,
   `os/api/assistant.php`, `os/api/assistant_lib.php`.
4. В студии нажмите «⇄ Связь»: агент скажет, доступны ли с сервера Overpass (здания и дороги
   OSM) и геокодер, и выведет дословный текст для поддержки хостинга, если сеть закрыта.

Изменены `index.html`, `sw.js`, `geoanalytics-studio.html`, `v420-geoanalytics.js`,
`v420-geo-studio.js`, `v4530-geo-export.js`, `v4730-geo-agent.js`. Новых файлов и миграций нет.

PHP на хостинге 8.0. Код совместим с PHP 7.2-8.4.

Проверка после заливки: в консоли браузера `CASE OS: все модули версии 4.73.1` и, в студии
геоаналитики, `CASE OS: модули гео-студии актуальны`.

Что посмотреть глазами, это и есть смысл выпуска:

1. «Гео: рынок и POI»: над студией нет списка проектов, только подсказка, «История /
   восстановление» и «↻».
2. В студии первая секция называется «Точка анализа» и говорит «не задана». Вкладки: Карта,
   Аналитика, Сравнение стран, Управление данными. На карте нет точек портфеля.
3. «▣ Аналитика по точке» без точки просит её поставить, а не считает центр города.
4. «📍 Точка на карте» (или в гео-агенте «📍 Точка», координаты, «адрес: …») ставит точку:
   в секции координаты и район, на карте одна метка со звездой. «▣ Аналитика по точке»
   открывает отчёт именно там; в выгрузке вместо имени проекта имя точки.

Целостность: `sha256sum -c SHA256SUMS_v4.73.1.txt` из папки `/os`.
