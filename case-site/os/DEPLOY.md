# CASE OS v4.76.0 - краткая установка

Студия геоаналитики по замечаниям владельца (пин без колец, цвет каждого кольца, полный
экран, левая панель сворачивается, подложка в панели инструментов, бизнес-центры с фильтрами,
списком, сравнением и тепловой картой ставок внутри студии, экран Geo Platform убран) и модель
доступа: типы пользователей, настройки на каждого, журнал, корзина геоданных, подписка со
сроком, регистрация, демо-вход. Что вошло: `CHANGELOG_CASE_OS_v4.76.0.md` в корне пакета.

1. Замените всё содержимое папки `/os` содержимым архива. `api/config.php` в архиве нет
   намеренно: ваш рабочий файл остаётся как есть (сохраните копию, если меняете папку целиком).
   Файлы, начинающиеся с точки (`.htaccess`, `api/.htaccess`, `api/.user.ini`), обязательны.
   Файл `geo-platform.html` из прежней версии можно удалить: он больше не используется.
2. Ctrl+Shift+R. В шапке `v4.76.0`.
3. База: войдите администратором, «Доступ» → карточка «Обновление базы данных» → «Применить
   миграции» (`2026_09_17_v4760_access.sql`: таблица корзины, роли CL и DEMO, колонки типа,
   срока и настроек у пользователей). Если миграцию не запустить, код дочинит колонки, роли и
   таблицу сам при первом обращении; миграция нужна, чтобы это было сделано явно и один раз.
4. Новые файлы: `v4760-access.js`, `v4760-geo-bc.js`, `v4760-geo-caps.js`,
   `sql/migrations/2026_09_17_v4760_access.sql`. Изменены `index.html`, `sw.js`,
   `geoanalytics-studio.html`, `v4750-geo-layout.js`, `v4750-geo-tools.js`, `v4740-geo-only.js`,
   `v3520-workspaces.js`, `v420-geo-studio.js`, `v420-geoanalytics.js`, `api/lib.php`,
   `api/auth.php`, `api/users.php`, `api/geo_state.php`, `api/state.php`. Удалён
   `geo-platform.html`.
5. Ключи `api/config.php` (все необязательные): `'allow_registration' => false` выключает
   регистрацию, `'demo_login' => false` выключает демо-вход, `'demo_email' => '...'` меняет
   адрес общего демо-пользователя (по умолчанию `demo@caseadvisory.local`).

PHP на хостинге 8.0. Код совместим с PHP 7.2-8.4.

Проверка после заливки: в консоли браузера `CASE OS: все модули версии 4.76.0` и, в студии
геоаналитики, `CASE OS: модули гео-студии актуальны`.

Что посмотреть глазами, это и есть смысл выпуска:

1. Экран входа: под кнопкой «Войти» ссылки «Регистрация» и «Демо-доступ». Демо открывает
   студию с 40 бизнес-центрами и пояснением вверху; выгрузки и правок нет.
2. В студии: `P` и клик ставят точку без колец; в «Зоне охвата» у каждого кольца своя кнопка
   цвета; внизу в панели кнопка подложки и ⛶ полного экрана; язычок слева сворачивает панель.
3. Секция «Бизнес-центры» слева: фильтры, счётчик, список, «Сравнить», показатели; в «Слои и
   стиль» → «Бизнес-центры» слой «Тепловая карта ставок». Вкладки «Сравнение стран» нет, в меню
   нет «Geo Platform».
4. «Доступ» (администратор): карточки «Заявки на регистрацию» (если есть), «Доступ, подписка и
   журнал» (тип, срок, выгрузка, правки, заметка, «Журнал»), «Корзина геоданных».
5. Поставьте пользователю срок «вчера»: его вход отвечает «Срок доступа истёк. Данные
   сохранены», запись остаётся в списке. Срок через 3 дня: после входа он видит предупреждение.

Целостность: `sha256sum -c SHA256SUMS_v4.76.0.txt` из папки `/os`.
