# CASE OS v4.46.4 — краткая установка

Полная инструкция находится в корне пакета: `CASE_OS_v4.46.4_DEPLOY_RU.md`.
Изменения только клиентские; `config.php` не затрагивается. Заливайте папку
`/os` ЦЕЛИКОМ — платформа теперь сама предупредит, если какой-то файл на
сервере остался старым (жёлтое сообщение при загрузке).

1. Замените всё содержимое папки `/os` содержимым архива `CASE_OS_v4.46.4_os_only.zip`.
2. Ctrl+Shift+R. Проверьте: в шапке `v4.46.4`, предупреждения о старых файлах нет.
3. Попросите сотрудников сделать Ctrl+Shift+R.
