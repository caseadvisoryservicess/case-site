# CASE OS v4.70.0 - краткая установка

Что вошло в релиз: `CHANGELOG_CASE_OS_v4.70.0.md` в корне пакета.
Базовая инструкция: `CASE_OS_v4.51.0_DEPLOY_RU.md` (порядок действий не менялся).

1. Замените всё содержимое папки `/os` содержимым архива.
2. Ctrl+Shift+R. В шапке `v4.70.0`.

Изменены `index.html`, `sw.js`, `v32-upgrade.js`, `v326-commission-engines.js`,
`v490-workflow.js`, `v492-portfolio-proposals.js`, `v493-portfolio-suite.js`.
Миграций базы нет.

Если миграция роли из v4.64.0 ещё не применялась, примените её сейчас:
`sql/migrations/2026_08_13_role_dir.sql`.

Проверка после заливки: в консоли браузера `CASE OS: все модули версии 4.70.0`.

Что проверить глазами: откройте «Инвесторы и запросы» и «Комиссии аренды» - шапка таблицы
теперь прилипает при прокрутке, ширину колонок можно тянуть, широкая таблица прокручивается
внутри себя, а не растягивает страницу. Откройте любой экран Advisory - заголовок раздела
стал такой же, как в аренде.

Целостность: `sha256sum -c SHA256SUMS_v4.70.0.txt` из папки `/os`.
