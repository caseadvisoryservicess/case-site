# CASE OS v4.46.1 — краткая установка

Полная инструкция находится в корне пакета: `CASE_OS_v4.46.1_DEPLOY_RU.md`.
Изменения только клиентские (index.html, sw.js, v35-stable.js, v420-geo-studio.js,
geoanalytics-studio.html, новый v4451-live-sync.js); `config.php` не затрагивается.
Если обновляетесь с v4.45.x — в архиве уже есть серверные файлы v4.46.0
(границы ролей, отчёт собственнику): после заливки один раз войдите администратором.

1. Замените содержимое папки `/os` содержимым архива `CASE_OS_v4.46.1_os_only.zip`.
2. Проверьте: в шапке `v4.46.1`, в `sw.js` cache key `case-os-v4461`.
3. Попросите сотрудников сделать Ctrl+Shift+R.
