# CASE OS v4.46.3 — краткая установка

Полная инструкция находится в корне пакета: `CASE_OS_v4.46.3_DEPLOY_RU.md`.
Изменения только клиентские (index.html, sw.js, v4327-patch.js); `config.php`
не затрагивается. Если обновляетесь с v4.45.x — в архиве уже есть серверные
файлы v4.46.0: после заливки один раз войдите администратором.

1. Замените содержимое папки `/os` содержимым архива `CASE_OS_v4.46.3_os_only.zip`.
2. Проверьте: в шапке `v4.46.3`, в `sw.js` cache key `case-os-v4463`.
3. Попросите сотрудников сделать Ctrl+Shift+R.
