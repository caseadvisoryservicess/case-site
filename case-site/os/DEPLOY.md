# CASE OS v4.50.3 — краткая установка

Полная инструкция в корне пакета: `CASE_OS_v4.50.3_DEPLOY_RU.md`.

1. Замените всё содержимое папки `/os` содержимым архива.
2. Ctrl+Shift+R. В шапке `v4.50.3`.

Закрывает находки внешнего аудита пакета v4.50.2. Изменены `index.html`, `core.js`,
`sw.js`, `.htaccess`, `api/backup.php`, `zarafshan-l2.svg`, добавлены `sql/.htaccess`
и `sql/backups/.htaccess`. Миграций базы нет.

ВАЖНО: после установки резервные копии базы начинают складываться ВЫШЕ публичной
папки — в `~/domains/caseadvisory.uz/caseos_backups`. Уже сделанные копии переезжают
туда автоматически при первом обращении к разделу бэкапов.
