# CASE OS v4.45.0 — краткая установка

Полная инструкция находится в корне пакета: `CASE_OS_v4.45.0_DEPLOY_RU.md`.
Обновлён серверный файл `api/lib.php` (время жизни сессии 12 ч) — копируется вместе со
всеми; `config.php` не затрагивается. После загрузки выполните hard reload.

1. Замените содержимое папки `/os` содержимым архива `CASE_OS_v4.45.0_os_only.zip`.
2. Проверьте: в шапке `v4.45.0`, в `sw.js` cache key `case-os-v4450`.
3. Попросите сотрудников сделать Ctrl+Shift+R и перезайти.
