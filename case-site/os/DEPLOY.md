# CASE OS v4.69.0 - краткая установка

Что вошло в релиз: `CHANGELOG_CASE_OS_v4.69.0.md` в корне пакета.
Базовая инструкция по установке и правам: `CASE_OS_v4.51.0_DEPLOY_RU.md` (порядок действий с тех пор не менялся).

1. Замените всё содержимое папки `/os` содержимым архива.
2. Ctrl+Shift+R. В шапке `v4.69.0`.

Добавлены `v4660-uz-translit.js`, `v4670-offer-pricing.js`, `v4680-project-directories.js`,
`v4690-offer-cover.js`, папка `assets/`. Изменены `index.html`, `sw.js`.
Миграций базы нет.

Если миграция роли из v4.64.0 ещё не применялась, примените её сейчас:
`sql/migrations/2026_08_13_role_dir.sql`.

Проверка после заливки: в консоли браузера должно быть `CASE OS: все модули версии 4.69.0`.
Если вместо этого появилось предупреждение с именами файлов, залита не вся папка `/os`.

Отдельно: положите две стандартные картинки титульного листа в `assets/` по именам
`offer-cover-1.jpg` и `offer-cover-2.jpg` - см. `assets/README.md`. Пока их нет, титул
собирает блок из цифр; пустой рамки в клиентском документе не появится.

Целостность: `sha256sum -c SHA256SUMS_v4.69.0.txt` из папки `/os`.
Файлы `api/config.php` и `api/config.local*.php` в архив не входят - они ваши,
их не перезаписывают.
