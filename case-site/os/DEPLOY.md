# CASE OS v4.49.2 — краткая установка

Полная инструкция находится в корне пакета: `CASE_OS_v4.49.2_DEPLOY_RU.md`.

⚠ В этом релизе появился НОВЫЙ файл `os/core.js` (код платформы, вынесенный из `index.html`).
Без него сайт не откроется. Заливайте папку `/os` ЦЕЛИКОМ, с перезаписью.

1. Замените всё содержимое папки `/os` содержимым архива `CASE_OS_v4.49.2_os_only.zip`.
2. Проверьте, что в `os/` есть файл `core.js`.
3. Ctrl+Shift+R. В шапке `v4.49.2`, предупреждения о старых файлах нет.
