# CASE OS v4.70.1 - краткая установка

Патч безопасности. Что вошло: `CHANGELOG_CASE_OS_v4.70.1.md` в корне пакета.

1. Замените всё содержимое папки `/os` содержимым архива.
2. Ctrl+Shift+R. В шапке `v4.70.1`.

Изменены `api/lib.php`, `api/state.php`, `api/unit_patch.php`, `api/units_batch.php`,
`core.js`, `index.html`, `sw.js`. Миграций базы нет.

Если миграция роли из v4.64.0 ещё не применялась, примените её сейчас:
`sql/migrations/2026_08_13_role_dir.sql`.

Проверка после заливки: в консоли браузера `CASE OS: все модули версии 4.70.1`.

Что проверить обязательно, это и есть смысл патча:

1. Войдите агентом аренды. В реестре ставки по-прежнему скрыты.
2. Нажмите «Экспорт CSV» - столбцов «Ставка $/м²» и «Бюджет $/м²» в файле быть НЕ должно.
3. Кнопки «Импорт CSV», «Блоки из кодов» и «GLA из юнитов» этой роли больше не показываются.
4. Войдите директором по аренде: все финансовые столбцы и кнопки на месте, ставки видны.
5. Отредактируйте помещение агентом (статус, брокер), сохраните, затем войдите директором -
   ставка и бюджет должны остаться прежними. Это главная проверка патча.

Целостность: `sha256sum -c SHA256SUMS_v4.70.1.txt` из папки `/os`.
