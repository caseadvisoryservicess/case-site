# CASE OS v4.42.1 — краткая установка

Полная инструкция находится в корне пакета: `CASE_OS_v4.42.1_DEPLOY_RU.md`.
SQL-миграций нет; серверные файлы не менялись. После загрузки выполните hard reload.

1. Замените содержимое папки `/os` содержимым архива `CASE_OS_v4.42.1_os_only.zip`.
2. Проверьте: в шапке `v4.42.1`, в `sw.js` cache key `case-os-v4421`.
3. Войдите администратором один раз — миграция дополнит шаблоны ролей (лечит «данные не сохраняются»).
