# CASE OS v4.47.1 — краткая установка

Полная инструкция находится в корне пакета: `CASE_OS_v4.47.1_DEPLOY_RU.md`.
Изменения только клиентские; `config.php` не затрагивается. Заливайте папку
`/os` ЦЕЛИКОМ — при частичной заливке платформа сама покажет жёлтое
предупреждение с именем старого файла.

1. Замените всё содержимое папки `/os` содержимым архива `CASE_OS_v4.47.1_os_only.zip`.
2. Ctrl+Shift+R. Проверьте: в шапке `v4.47.1`, предупреждения о старых файлах нет.
3. Попросите сотрудников сделать Ctrl+Shift+R.
