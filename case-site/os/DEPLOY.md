# CASE OS v4.70.3 - краткая установка

Выпуск только по безопасности, новых возможностей нет. Что вошло:
`CHANGELOG_CASE_OS_v4.70.3.md` в корне пакета.

1. Замените всё содержимое папки `/os` содержимым архива.
2. Ctrl+Shift+R. В шапке `v4.70.3`.

Изменены `index.html`, `core.js`, `sw.js`, `api/lib.php`, `.htaccess`. Миграций базы нет.

Файл `.htaccess` в папке `/os` обязателен: в нём живут заголовки безопасности. Если
панель хостинга скрывает файлы, начинающиеся с точки, включите в файловом менеджере
показ скрытых файлов, иначе он не зальётся и защита просто исчезнет - молча.

Если миграция роли из v4.64.0 ещё не применялась, примените её сейчас:
`sql/migrations/2026_08_13_role_dir.sql`.

Проверка после заливки: в консоли браузера `CASE OS: все модули версии 4.70.3`.

Что проверить после обновления. Правки этого выпуска невидимы глазом, поэтому проверка
идёт не по внешнему виду, а по трём наблюдаемым признакам:

1. **Все сотрудники должны войти заново - это ожидаемо.** Сессионная cookie меняет
   параметры, старая перестаёт подходить. Один раз, при первом входе после обновления.
   Если вход не проходит и со второй попытки, платформа открыта по `http://` без
   сертификата: откройте её по `https://`.
2. **Карты Яндекса.** Раздел с картой, где введён ключ API, должен показать карту.
   Раньше на этом месте был баннер «Проверьте API-ключ и подключение», причём ключ был
   верным - загрузку резала своя же политика безопасности.
3. **Планировки.** Откройте планировку объекта: коды помещений и названия брендов на
   месте, ничего не пропало.

Целостность: `sha256sum -c SHA256SUMS_v4.70.3.txt` из папки `/os`.
