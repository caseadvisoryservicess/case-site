# CASE OS v4.64.0 - краткая установка

Что вошло в релиз: `CHANGELOG_CASE_OS_v4.64.0.md` в корне пакета.
Базовая инструкция по установке и правам: `CASE_OS_v4.51.0_DEPLOY_RU.md` (порядок действий с тех пор не менялся).

1. Замените всё содержимое папки `/os` содержимым архива.
2. Ctrl+Shift+R. В шапке `v4.64.0`.
3. **Примените миграцию базы** `sql/migrations/2026_08_13_role_dir.sql` - без неё новая роль
   в базе не появится, и назначить её из раздела «Доступ» будет нельзя.
   Способ: phpMyAdmin -> вкладка SQL -> вставить содержимое файла -> Go. Повторный запуск безопасен.

Изменены `index.html`, `core.js`, `v3520-workspaces.js`, `sw.js`.
Добавлена миграция `sql/migrations/2026_08_13_role_dir.sql`.

Проверка после заливки: в консоли браузера должно быть `CASE OS: все модули версии 4.64.0`,
а при открытой гео-студии - `CASE OS: модули гео-студии актуальны`. Если вместо этого
появилось предупреждение с именами файлов, залита не вся папка `/os`.

Проверка миграции: в разделе «Доступ» в списке ролей должна появиться
`Директор (без администрирования)`. Если её нет - миграция не применена.

Целостность: `sha256sum -c SHA256SUMS_v4.64.0.txt` из папки `/os`.
Файлы `api/config.php` и `api/config.local*.php` в архив не входят - они ваши,
их не перезаписывают.
