# CASE OS v4.42.0 — краткая установка

Полная инструкция находится в корне пакета: `CASE_OS_v4.42.0_DEPLOY_RU.md`.
SQL-миграций нет; серверные файлы не менялись. После загрузки выполните hard reload.

1. Замените содержимое папки `/os` содержимым архива `CASE_OS_v4.42.0_os_only.zip`.
2. Проверьте: в шапке `v4.42.0`, в `sw.js` cache key `case-os-v4420`.
3. Войдите администратором один раз — миграция вернёт младшему админу гео/бренды.
