# CASE OS v4.47.0 — пересборка табличного ядра

Дата: 2026-07-25. По вашим запросам «надо пересобрать все таблицы, а то друг на
друга пишем коды» и «исправь сразу».

## Что сделано

**1. Один владелец всей презентации таблиц.** Код прилипшей шапки (клон,
синхронизация, проброс резайзеров и кликов, прокрутка-передача колёсиком)
целиком переехал из модуля-патча (v4327) в модуль-грид (v432) — туда же, где
живут ширины, плотность, закрепление, скрытие столбцов и фильтры. Больше нет
двух модулей, которые управляют одной шапкой и перебивают CSS друг друга —
источник всех «белых пятен», «съехавших столбцов» и «полосок» последних дней.
Модуль-патч теперь отвечает только за очередь синхронизации правок и
специфику внешнего агента.

**2. Страховка от старых файлов на хостинге.** Даже если при заливке какой-то
модуль на сервере остался старым, index.html теперь сам несёт критичные
правила: закрепление столбцов в шапке и контролы в границах ячеек работают
в любом случае. Проверено специальной смешанной сборкой (новый index + старый
v4327-patch со сломанным правилом): закрепление в основной шапке работает,
«белых пятен» нет — а о самом старом файле платформа сообщает жёлтым
предупреждением с его именем (механизм v4.46.4).

**3. Все накопленные исправления сохранены**: пересборка клона по «отпечатку»
шапки, синхронизация после применения закрепления, слой-скроллконтейнер,
живая синхронизация без перерисовок, точечные обновления после сохранений.
