# CASE OS v4.45.0 — установка на хостинг (DirectAdmin)

Включает всё из v4.42.x–v4.44.0 (в т.ч. 12-часовую сессию из v4.44.0 — файл
`api/lib.php` в архиве). `config.php` не затрагивается, SQL вручную не нужен.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.45.0_os_only.zip` (или FULL-пакет — сайт+платформа+доки).
2. Замените содержимое `/os` файлами из архива.
3. Жёсткая перезагрузка: **Ctrl+Shift+R**. В шапке — **v4.45.0**.
4. Попросите сотрудников сделать Ctrl+Shift+R и перезайти.

## Проверка

1. LCR → открыть карточку помещения → изменить и сохранить → таблица за карточкой
   обновилась сразу, прокрутка на месте.
2. Прокрутите LCR вниз (шапка прилипла) → потяните границу столбца прямо в прилипшей
   шапке — ширина меняется.
3. LCR и База брендов — в едином «гео»-виде: просторные строки, счётчик
   «Показано N строк · M столбцов» над таблицей.
