# CASE OS v4.43.3 — установка на хостинг (DirectAdmin)

Включает всё из v4.42.x–v4.43.2 + мгновенное отображение правок в таблицах.
Серверные файлы в этом релизе не менялись; `config.php` не затрагивается.

## Шаги (5 минут)

1. Скачайте `CASE_OS_v4.43.3_os_only.zip` (без секретов).
2. Замените содержимое `/os` файлами из архива.
3. Жёсткая перезагрузка: **Ctrl+Shift+R**. В шапке — **v4.43.3**.
4. Если не делали после v4.42.1 — один вход администратором (миграция шаблонов ролей).

## Проверка

«Контроль аренды (LCR)» → «План / бюджет» → «✎Правка» → измените базовую аренду в
любой строке: «Итого аренда» и «Итого вкл. обсл.» пересчитаются сразу же, без
перезагрузки; курсор останется в поле — можно продолжать вводить значения подряд.
