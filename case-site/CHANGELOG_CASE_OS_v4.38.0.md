# CASE OS v4.38.0 — Changelog

Дата релиза: 24 июля 2026 г.

## Единый скин таблиц и вкладок во всех модулях

- Таблицы модулей v32 (SCR/продажи), v326 (комиссии) и case49 (задачи/Advisory)
  приведены к эталону «Базы брендов»: серый КАПС-заголовок, зебра, ховер-подсветка,
  одинаковые отступы и размер шрифта. Проверено программно: computed-стили шапок
  всех четырёх видов таблиц идентичны.
- Таббары гео-модулей и «Версий планировок» (.geo-tabbar) приведены к виду вкладок
  ядра (.tabs): те же скругления, цвета и активное состояние.
- Реализация — приоритетные правила в ядре (#main-селекторы), CSS модулей не трогался:
  порядок загрузки модулей больше не влияет на вид.
- Исправлена ещё одна устаревшая подсказка: пустое состояние SCR ссылалось на
  кнопку «✎ Объект» в шапке — теперь указывает на живую кнопку «✎ Настройки объекта».
