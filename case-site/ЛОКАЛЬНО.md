# CASE OS — локальный сервер на вашем ПК (для тестов до боевого хостинга)

Цель: поднять на компьютере «сервер» (PHP + MySQL), поставить туда платформу
и прогнать сценарии — точно так же, как будет на caseadvisory.uz, но локально.

Технических знаний не нужно — повторяйте по пунктам.

---

## 1. Что поставить (одна программа)
Выберите одно:
- **XAMPP** — для Windows / Mac / Linux. Универсально. https://www.apachefriends.org
- **Laragon** — только Windows, ещё проще. https://laragon.org

Внутри уже есть Apache (веб‑сервер), PHP, MySQL и phpMyAdmin.

Дальше — на примере **XAMPP** (Laragon — аналогично).

---

## 2. Установка и запуск
1. Скачать и установить XAMPP (всё по умолчанию).
2. Открыть **XAMPP Control Panel**.
3. Нажать **Start** напротив **Apache** и **MySQL** (оба должны загореться зелёным).

---

## 3. Положить файлы платформы
1. Найти папку XAMPP → внутри **htdocs** (обычно `C:\xampp\htdocs`).
2. Скопировать туда папку **os** (с файлами `index.html`, `sw.js`, `api/`, `sql/`).
   Должно получиться: `C:\xampp\htdocs\os\...`

Проверка: откройте в браузере `http://localhost/os/` — платформа откроется.

---

## 4. Создать базу данных
1. Открыть `http://localhost/phpmyadmin`
2. Слева **New** → имя базы, например `caseos` → **Create**.
3. Выбрать базу `caseos` → вкладка **Import** → выбрать файл
   `os/sql/schema_mysql.sql` → **Go**.
4. Ещё раз **Import** → файл `os/sql/seed_roles.sql` → **Go**.

(Локально пользователь БД обычно `root`, пароль пустой.)

---

## 5. Настроить подключение
1. В папке `os/api/` сделать копию `config.sample.php` → назвать `config.php`.
2. Открыть `config.php` в «Блокноте» и вписать:
   - `'driver' => 'mysql'`
   - `'host'   => 'localhost'`
   - `'name'   => 'caseos'`
   - `'user'   => 'root'`
   - `'pass'   => ''`   (пусто)
3. Сохранить.

---

## 6. Создать администратора и проверить
1. Открыть `http://localhost/os/api/setup.php` → ввести email/пароль/имя → создать.
2. Удалить `setup.php` из `os/api/` (как и на боевом).
3. Открыть `http://localhost/os/` — платформа.

---

## 7. Что можно прогнать уже сейчас
- Саму платформу (все разделы, роли, документы, языки RU/UZ/EN).
- Бэкенд (вход/права/данные) — через адреса `http://localhost/os/api/...`
  (это API; ниже — про подключение интерфейса к нему).

## 8. Полный прогон end‑to‑end (интерфейс ↔ база ↔ вход)
Чтобы интерфейс читал/писал в локальную базу и работал реальный вход —
нужно доделать **P2** (подключение `index.html` к API). Это я делаю, а вы
проверяете на своём `localhost`. Порядок:
1. Вы ставите XAMPP (пункты 1–3).
2. Я выдаю версию с подключением к API (P2).
3. Вы кладёте файлы, импортируете базу, создаёте админа (пункты 4–6).
4. Прогоняем все сценарии локально.
5. Только после успешного теста — заливаем на caseadvisory.uz.

---

## Частые вопросы
- **Порт занят / Apache не стартует:** обычно мешает Skype или другой сервер
  на порту 80. В XAMPP можно сменить порт Apache на 8080 → адрес станет
  `http://localhost:8080/os/`.
- **Белый экран:** проверьте `config.php` (имя базы / user / пароль).
- **Изменения не видны:** обновите страницу Ctrl+F5.
- **Сбросить и начать заново:** в phpMyAdmin удалить базу и заново Import.
