# CASE OS — переезд на хостинг: пошагово (DirectAdmin, caseadvisory.uz)

Инструкция под вашу панель **DirectAdmin** (`caseadvisory.uz:2222`).

Что понадобится:
- вход в панель DirectAdmin (логин `wwwcasea`);
- архив платформы **case-os-v2.30.zip** (или новее) на вашем компьютере;
- 30–40 минут.

Ваш PHP 7.4 подходит (проверено). По желанию можно поднять до 8.x:
**Инструменты → Select PHP version** — платформа работает на обоих.

---

## Шаг 1. Загрузить файлы на хостинг

1. В панели: **Система и файлы → Менеджер файлов**.
2. Откройте папку **public_html** (или `domains/caseadvisory.uz/public_html`).
3. Нажмите **Upload / Загрузить** и загрузите `case-os-v2.30.zip`.
4. Отметьте архив → **Extract / Распаковать** прямо в `public_html`.
5. Проверьте, что появилась папка `os` и внутри неё:
   `public_html/os/index.html`, `public_html/os/api/`, `public_html/os/sql/`.
6. Сам архив с сервера удалите.

## Шаг 2. Проверить HTTPS (замочек)

Откройте в браузере `https://caseadvisory.uz/os/` — должен быть замочек.
Если сертификата нет: **Управление аккаунтом → SSL-сертификаты** →
включите бесплатный **Let's Encrypt** для caseadvisory.uz (+ www) → Save.
Без HTTPS вход и офлайн-режим работать не будут.

## Шаг 3. Создать базу данных

**Управление аккаунтом → Базы данных → Create new Database**:

1. Имя базы: `os` → система добавит префикс, получится **`wwwcasea_os`**.
2. Пользователь: `os` → получится **`wwwcasea_os`**.
3. Пароль: нажмите генерацию и **сохраните его**.
4. **Create**.

Запишите три значения — они нужны в шаге 6:
имя базы `wwwcasea_os`, пользователь `wwwcasea_os`, пароль.

## Шаг 4. Импортировать таблицы

**Инструменты → phpMyAdmin** (вход — логин/пароль базы из шага 3):

1. Слева нажмите на базу **wwwcasea_os**.
2. Вкладка **Import / Импорт** → «Выберите файл» — файлы берите из
   распакованного архива на вашем компьютере, папка `os/sql/`:
   - сначала `schema_mysql.sql` → **Go / Вперёд**;
   - затем `seed_roles.sql` → **Go**.

⚠️ Файл `install_all.sql` — только для локального XAMPP. На хостинге его
использовать **не надо**: он пытается сам создать базу `caseos`, хостинг это
не разрешит.

**Вариант Б — перенести данные с локального XAMPP** (если наработанное локально
нужно сохранить): на своём компьютере откройте `localhost/phpmyadmin` → база
`caseos` → вкладка **Экспорт** → «Быстрый» → скачается `caseos.sql`. На
хостинге в phpMyAdmin выберите базу **wwwcasea_os** → **Импорт** → этот файл
(вместо пунктов выше). Тогда шаг 7 (setup.php) пропускаете — пользователи уже
перенесены; проверьте только, что у всех **настоящие** email-адреса.

## Шаг 5. Создать почтовый ящик для кодов входа

**Управление E-mail → E-Mail Аккаунты → Create Account**:
- имя: `no-reply` → получится **no-reply@caseadvisory.uz**;
- пароль — придумайте и **сохраните**.

С этого ящика платформа будет отправлять сотрудникам коды входа.

## Шаг 6. Заполнить config.php

**Менеджер файлов** → `public_html/os/api/`:

1. Скопируйте `config.sample.php` → назовите копию `config.php`.
2. Откройте `config.php` на редактирование (**Edit**) и впишите:

```php
<?php
return [
  'driver' => 'mysql',
  'host'   => 'localhost',
  'name'   => 'wwwcasea_os',
  'user'   => 'wwwcasea_os',
  'pass'   => 'ПАРОЛЬ_БАЗЫ_ИЗ_ШАГА_3',
  'charset'=> 'utf8mb4',
  'sqlite_path' => __DIR__ . '/caseos.sqlite',
  'backup_token' => 'ПРИДУМАЙТЕ_ДЛИННУЮ_СЛУЧАЙНУЮ_СТРОКУ',
  'mail_from' => 'no-reply@caseadvisory.uz',
  'smtp' => [
    'host'   => 'mail.caseadvisory.uz',
    'port'   => 465,
    'secure' => 'ssl',
    'user'   => 'no-reply@caseadvisory.uz',
    'pass'   => 'ПАРОЛЬ_ЯЩИКА_ИЗ_ШАГА_5',
  ],
];
```

⚠️ Строки `'code_login' => false` здесь быть **не должно** — она была только
для локального XAMPP. Без неё вход работает по коду из письма (как задумано).

## Шаг 7. Создать первого администратора

1. Откройте `https://caseadvisory.uz/os/api/setup.php`.
2. Введите **ваш настоящий email** (на него будут приходить коды входа),
   пароль и имя → «Создать администратора».
3. **Обязательно** удалите файл: Менеджер файлов →
   `public_html/os/api/setup.php` → **Delete**.

## Шаг 8. Проверить вход

1. Откройте `https://caseadvisory.uz/os/`.
2. Введите email из шага 7 → **«Получить код»**.
3. Откройте почту (проверьте «Спам») → введите 6-значный код → **«Войти»**.

## Шаг 9. Добавить сотрудников

В платформе: раздел **«Пользователи»** (виден только администратору) →
добавляйте каждого сотрудника с его **настоящим рабочим email** — именно на
него приходит код входа.

## Шаг 10 (желательно). Автобэкап раз в день

**Доп. возможности → Cron задания → Create Cron Job**:
- время: минута `0`, час `3`, остальное `*` (каждый день в 03:00);
- команда (подставьте ваш `backup_token` из шага 6):

```
curl -s "https://caseadvisory.uz/os/api/backup.php?token=ВАШ_BACKUP_TOKEN" >/dev/null
```

Копии базы складываются в `os/sql/backups/` и хранятся 30 дней. Вручную бэкап
можно сделать кнопкой в платформе (раздел администрирования).

## Если что-то пошло не так

| Симптом | Причина и решение |
|---|---|
| «Неизвестное действие» при входе | На сервер попала не вся папка `os/api` — перезалейте её целиком из архива. |
| «Хостинг не отправил письмо» | Проверьте блок `smtp` в config.php: host `mail.caseadvisory.uz`, порт 465/ssl, точный пароль ящика. Аварийно: добавьте `'allow_password_login' => true,` — временно включится вход по паролю; после починки почты строку уберите. |
| Письмо не приходит | Проверьте «Спам». Новый код можно запросить не чаще раза в минуту. |
| «Этот email не зарегистрирован» | В «Пользователи» проверьте точное написание email сотрудника. |
| Ошибка базы при открытии | Сверьте `name` / `user` / `pass` в config.php с шагом 3. |
| Обновление не видно | Обновите страницу с очисткой кэша: **Ctrl+F5**. |

## Обновления платформы в будущем

Из нового архива замените на хостинге: `os/index.html`, `os/sw.js`,
`os/quiz-data.js` и папку `os/api` (ваш `config.php` **не трогать** — он в
архивы не входит и не перезаписывается). После замены — Ctrl+F5 в браузере.

Локальный XAMPP можно оставить как тренировочный: с `'code_login' => false`
он продолжит работать по паролю независимо от хостинга.
