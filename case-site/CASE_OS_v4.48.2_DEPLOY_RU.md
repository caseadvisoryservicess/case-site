# CASE OS v4.48.2 — установка на хостинг (DirectAdmin)

Закреплённые столбцы теперь показывают свои заголовки всегда (угловой блок),
белых пятен нет. Подробности — `CHANGELOG_CASE_OS_v4.48.2.md`.

## Шаг 1. Файлы — залить ЦЕЛИКОМ

Замените ВСЁ содержимое папки `/os` содержимым архива
`CASE_OS_v4.48.2_os_only.zip`. `api/config.php` не затрагивается. Серверные PHP
не менялись.

## Шаг 2. Проверка (2 минуты)

1. Ctrl+Shift+R → в шапке **v4.48.2**, жёлтого предупреждения о старых файлах нет.
2. ЛСР → «☷ Столбцы» → закрепить 3–4 → прокрутите вправо: слева стоит блок
   с заголовками закреплённых столбцов ровно над их телом.
3. Прокрутите вниз и снова вправо-влево: заголовки колонок прилипли сверху,
   угловой блок всегда в углу, линии сходятся.
4. Потяните ширину столбца прямо в угловом блоке — работает.
5. Белых пятен над шапкой нет.
