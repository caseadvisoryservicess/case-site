# CASE OS v4.32.7 — staging acceptance checklist

## A. Версия и кэш

- [ ] В верхней панели отображается `v4.32.7`.
- [ ] В Network загружен `v4327-patch.js?v=4.32.7`.
- [ ] В Network загружен `v432-data-grid.js?v=4.32.7`.
- [ ] Старый `v4326-patch.js` не загружается.
- [ ] После hard reload интерфейс не использует старый Service Worker cache.

## B. LCR — прокрутка вниз

- [ ] Открыть проект с достаточным количеством юнитов.
- [ ] Прокрутить страницу/таблицу вниз.
- [ ] Строка `БЮДЖЕТ / ФАКТ` видна полностью.
- [ ] Строка названий колонок видна полностью.
- [ ] Две строки не перекрываются и не обрезаются.
- [ ] Закреплённая шапка находится ниже верхней панели CASE OS.
- [ ] Ячейки шапки совпадают с колонками тела таблицы.

## C. LCR — возврат наверх

- [ ] Прокрутить внутреннюю таблицу к первой строке.
- [ ] Продолжить крутить колесо вверх.
- [ ] Прокрутка автоматически переходит к странице.
- [ ] Можно подняться до заголовка проекта и верхней панели без перетаскивания scrollbar вручную.
- [ ] Нет «залипания» или циклического рывка на границе.

## D. Нижняя граница

- [ ] Дойти до нижней границы внутренней таблицы.
- [ ] Продолжить прокрутку вниз.
- [ ] Прокрутка передаётся внешней странице/контейнеру.

## E. Горизонтальная прокрутка

- [ ] Сдвинуть таблицу горизонтально вправо.
- [ ] Закреплённая шапка движется синхронно.
- [ ] Заголовки остаются над своими значениями.
- [ ] Вертикальная передача прокрутки не мешает горизонтальной.

## F. Фильтры и resize

- [ ] Открыть фильтр из закреплённой шапки.
- [ ] Открывается меню правильного столбца.
- [ ] Изменить ширину столбца в исходной шапке.
- [ ] После отпускания закреплённая шапка обновляет ширину.
- [ ] После повторной прокрутки линии остаются совмещёнными.

## G. Разные размеры

- [ ] Проверить широкий монитор.
- [ ] Проверить стандартный ноутбук.
- [ ] Проверить уменьшенное окно браузера.
- [ ] При изменении высоты верхней панели sticky-шапка не перекрывает её.

## H. Регрессия

- [ ] LCR данные и статусы сохранены.
- [ ] Переключение `Бюджет / Факт` работает как в v4.32.5.
- [ ] Resize колонок работает.
- [ ] Таблица брендов работает.
- [ ] SCR работает.
- [ ] Геоданные открываются и фильтруются.
