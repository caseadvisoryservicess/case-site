# Панель управления лендингами

Админ-панель для агентов: вход по логину/паролю, редактирование лендингов своих
проектов и создание новых (тексты на 3 языках, фото, лоты, FAQ) — на выходе
готовый лендинг в фирменном дизайне.

## Запуск

```bash
cd admin
npm install
node server.js          # порт 3000, либо PORT=8080 node server.js
```

Панель: `http://localhost:3000` · Собранные лендинги: `http://localhost:3000/p/<slug>/`

При первом запуске создаётся пользователь **admin / admin** — сразу смените
пароль (раздел «Пользователи»).

## Роли

- **Админ** — все проекты, создание лендингов, управление пользователями.
- **Агент** — только назначенные ему проекты (редактирование, сборка, выгрузка).

## Как устроено

- `data/projects/<slug>/project.json` — весь контент лендинга (RU обязателен, UZ/EN опциональны — где перевода нет, показывается русский);
- `data/projects/<slug>/uploads/` — загруженные фото;
- `lib/template.js` — генератор страницы (дизайн, SEO-разметка, форма заявки);
- `sites/<slug>/` — собранный статичный лендинг: можно раздавать прямо с панели
  (`/p/<slug>/`) или скачать zip и выложить на любой хостинг.

Заявки с лендингов идут на почту (FormSubmit) и, если в проекте указан URL
Google Apps Script (поле «Google Таблица»), — строкой в CRM-таблицу
(см. `../takhtapul/crm-apps-script.gs`).

## Деплой

Любой Node-хостинг: Render / Railway / Fly / VPS. Команда старта — `node server.js`,
персистентной должна быть папка `admin/data` (и желательно `admin/sites`).
За HTTPS-доменом панель можно спрятать за nginx или использовать встроенный
прокси хостинга.
