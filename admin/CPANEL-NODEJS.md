# Установка панели через «Setup Node.js App» (ваш хостинг, cPanel-подобный)

У вас на хостинге есть встроенный модуль для Node.js-приложений — значит,
панель можно поставить прямо на caseadvisory.uz, без сторонних сервисов.
Итоговая схема: `caseadvisory.uz/taxtapul` — лендинг, `caseadvisory.uz/admin`
— панель с CRM.

---

## Шаг 1. Лендинг (если ещё не залили)

Как в прошлой инструкции: `taxtapul-landing.zip` → Файловый менеджер →
`public_html` → папка `taxtapul` → загрузить zip → Extract прямо в неё.
Проверка: `caseadvisory.uz/taxtapul` открывается.

## Шаг 2. Создаём Node.js-приложение

1. В верхнем меню: **Инструменты → Setup Node.js App**.
2. Кнопка **«Create Application»** (Создать приложение).
3. Заполните поля:
   - **Node.js version** — выберите самую свежую доступную (18, 20 или 22 — любая подойдёт, крайне желательно не ниже 18);
   - **Application mode** — `Production`;
   - **Application root** — `admin_panel` (это папка внутри вашего аккаунта, НЕ внутри public_html — так безопаснее, файлы панели не будут видны напрямую);
   - **Application URL** — выберите домен `caseadvisory.uz` и в поле пути (там, где после домена) впишите `admin`. Итоговый адрес должен получиться `caseadvisory.uz/admin`;
   - **Application startup file** — `server.js`.
4. Нажмите **Create**. Хостинг создаст папку `admin_panel` и покажет карточку приложения со статусом.

## Шаг 3. Загружаем файлы панели в эту папку

1. **Инструменты → Менеджер файлов** (File Manager).
2. Найдите папку **admin_panel** (она в корне аккаунта, на уровень выше public_html — в дереве слева, там же, где вы видели `.php`, `Maildir`, `public_html`).
3. Зайдите внутрь → **Загрузить** → выберите **sfb-platforma.zip**.
4. Выделите загруженный zip → **Extract** — файлы (`server.js`, `package.json`, папки `lib`, `public`, `data`…) должны оказаться прямо в `admin_panel`, без вложенной папки. Если создалась лишняя папка внутри — зайдите в неё, выделите всё содержимое, «Переместить» на уровень выше в `admin_panel`, затем удалите опустевшую папку.
5. Проверьте, что рядом с `server.js` лежит `package.json` — если да, всё на месте.

## Шаг 4. Устанавливаем зависимости

1. Вернитесь на страницу **Setup Node.js App** → откройте карточку вашего приложения.
2. Там есть команда для терминала вида:
   ```
   source /home/ВАШ_ЛОГИН/nodevenv/admin_panel/20/bin/activate && cd /home/ВАШ_ЛОГИН/admin_panel
   ```
   Скопируйте её (кнопка рядом обычно копирует автоматически).
3. Откройте **Инструменты → Терминал** (Terminal — он тоже виден в вашем меню «Система и файлы»).
4. Вставьте скопированную команду, нажмите Enter.
5. Затем выполните:
   ```
   npm install
   ```
   Подождите 1–2 минуты, пока установятся зависимости (express, bcryptjs, multer, archiver).

## Шаг 5. Переменная окружения — пароль администратора

1. Вернитесь на **Setup Node.js App** → в карточке приложения найдите раздел
   **Environment Variables** (Переменные окружения).
2. Добавьте: имя `ADMIN_PASSWORD`, значение — придумайте свой пароль (запомните его).
3. Сохраните.

## Шаг 6. Запуск

1. В карточке приложения нажмите **Restart** (или «Start», если ещё не запущено).
2. Подождите несколько секунд, статус должен стать «Running» / зелёным.
3. Откройте **caseadvisory.uz/admin** в браузере — должна открыться форма входа.
4. Логин `admin`, пароль — тот, что задали в ADMIN_PASSWORD.

Если вместо формы входа — ошибка 503 или белый экран: откройте в карточке
приложения **Log file** / «Detailed Error Log» — там будет причина (обычно
либо не выполнен `npm install`, либо не тот стартовый файл). Можно прислать
мне текст ошибки — разберу.

## Шаг 7. Связать лендинг и панель

Панель → войти → открыть проект **Тахтапул** → вкладка **«Основное»**:

- **Кнопка «Войти» на лендинге** → `/admin/` (именно так, лендинг и панель
  теперь на одном домене — сработает короткий путь без полного адреса);
- **Приём заявок (URL)** → оставьте пустым — панель сама определит адрес
  (по умолчанию она шлёт заявки на себя же, `../../api/lead/takhtapul`,
  это сработает автоматически на одном домене);
- **E-mail для лидов** → ваши почты через запятую.

Нажмите **«Сохранить и собрать»** → **«Скачать сайт (zip)»** → перезалейте
в папку `public_html/taxtapul` (замените старые файлы).

## Шаг 8. Проверка

1. `caseadvisory.uz/taxtapul` → в шапке появилась кнопка **«Войти»** →
   ведёт на `caseadvisory.uz/admin`.
2. Отправьте тестовую заявку с лендинга.
3. Она должна появиться в панели, раздел **«Лиды»**, и прийти письмом
   (в первом письме от FormSubmit нажмите кнопку подтверждения).
4. Раздел **«Пользователи»** → создайте логины агентам.

Готово — вся система на одном хостинге, обновление лендинга и текстов
теперь занимает одну кнопку «Сохранить и собрать» в панели, файлы
перезаливать вручную для правок текста/фото уже не нужно (только если
меняете adminUrl/leadEndpoint — тогда пересобранный zip лендинга всё же
нужно перезалить, так как сам лендинг остаётся статикой в public_html).

public_html/taxtapul.
